# AI Works Portfolio

เว็บไซต์แบบ static (HTML/CSS/JS ล้วน ๆ ไม่ต้อง build) สำหรับรวบรวมผลงานที่สร้างขึ้นด้วยความช่วยเหลือของ AI ทุกประเภท — ภาพ วิดีโอ เพลง งานเขียน โค้ด และอื่น ๆ

ไม่เกี่ยวข้องกับโปรเจกต์ caveman หลักในรีโปนี้ อยู่แยกเป็นโฟลเดอร์ของตัวเอง

## วิธีเปิดดู

เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ได้ทันที ไม่ต้องมีเซิร์ฟเวอร์หรือ build step

หรือถ้าอยากรันผ่าน local server (ไม่บังคับ):

```bash
cd portfolio-site
python3 -m http.server 8000
# แล้วเปิด http://localhost:8000
```

## วิธีเพิ่ม/แก้ไขผลงาน

แก้ไขไฟล์ [`assets/data/works.js`](./assets/data/works.js) — เป็น array ธรรมดา แต่ละชิ้นมีฟิลด์:

| ฟิลด์ | คำอธิบาย |
|---|---|
| `id` | เลขไม่ซ้ำกัน |
| `title` | ชื่อผลงาน |
| `category` | หนึ่งใน `image`, `video`, `writing`, `code`, `music`, `other` |
| `tool` | ชื่อเครื่องมือ AI ที่ใช้ เช่น Midjourney, Claude, Suno |
| `description` | คำอธิบายสั้น ๆ |
| `date` | วันที่ รูปแบบ `YYYY-MM-DD` |
| `link` | ลิงก์ไปดูผลงานฉบับเต็ม |
| `thumbnail` | อีโมจิ (หรือจะเปลี่ยนเป็น URL รูปภาพก็ได้ ต้องแก้ CSS/JS เพิ่มเล็กน้อย) |

เพิ่มรายการใหม่โดย copy object ที่มีอยู่แล้วแก้ค่า ไม่ต้องแตะไฟล์อื่น

## โครงสร้างไฟล์

```
portfolio-site/
├── index.html          # โครงหน้าเว็บ
├── assets/
│   ├── style.css        # ธีม สี ฟอนต์ responsive layout
│   ├── script.js         # filter / search / modal
│   └── data/
│       └── works.js      # ข้อมูลผลงานทั้งหมด — แก้ที่นี่
└── README.md
```

## ฟีเจอร์

- กรองผลงานตามหมวดหมู่ (ภาพ, วิดีโอ, งานเขียน, โค้ด, เพลง, อื่น ๆ)
- ค้นหาด้วยชื่อผลงาน / เครื่องมือ AI / คำอธิบาย
- คลิกการ์ดเพื่อดูรายละเอียดแบบ modal
- รองรับ dark mode ตามการตั้งค่าเครื่อง
- responsive ใช้งานได้ตั้งแต่จอมือถือ
