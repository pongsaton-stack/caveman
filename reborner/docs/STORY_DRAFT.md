## 2. Riona

> ✅ Pongsaton ตัดสินแล้ว (25 ก.ย. 2026): แนว **เกิดใหม่แบบ "เกิดชาตินี้พี่ต้องเทพ"**
> ตายเพราะลูกหลงสงครามในอารยธรรมเก่า ได้โอกาสใช้ชีวิตใหม่ โดยยังจำชีวิตเดิมได้ ชีวิตเดิมเป็นโอตาคุและเด็กติดเกม
> ยืมแค่โครง "เกิดใหม่พร้อมความรู้เดิม + ชีวิตแรกที่เสียดาย" ไม่ยืมตัวละคร ฉาก หรือเหตุการณ์ของเรื่องนั้น

### ใครคือ Riona
- **ชาติก่อน:** เด็กติดเกมและโอตาคุในโลกเก่า อายุ 17 ใช้ชีวิตเกือบทั้งหมดอยู่หน้าจอ ไม่ค่อยออกจากห้อง
- **ตาย:** เพราะลูกหลงสงครามที่ทำให้อารยธรรมเก่าล่มสลาย ไม่ได้เป็นทหาร ไม่ได้สู้ แค่อยู่ผิดที่ผิดเวลา
  ตอนนั้นในมือมี **มีดทำครัว** ที่คว้ามาจากครัวที่บ้าน → อาวุธเริ่มต้น (`PlayerState` · ค่า 14)
- **ชาตินี้:** ตื่นขึ้นในทุ่งเถ้าในร่างอายุเท่าเดิม ไม่รู้ว่าผ่านไปกี่ร้อยปี
  เป็นโอกาสครั้งที่สองที่เธอตั้งใจว่า **"รอบนี้จะใช้ชีวิตจริงๆ"**
- หน้าตาตามเฟรมที่มีแล้วใน `assets/sprites/hero/`: ผมน้ำตาลสั้นยุ่ง เสื้อเชิ้ตขาวใต้เสื้อกั๊กเขียวอมฟ้า กางเกงเขียวเข้ม รองเท้าบูทน้ำตาล

### ความรู้เดิมจากชีวิตเกมเมอร์ = เหตุผลของกลไก
| ความรู้เดิม | ผูกกับกลไก |
|---|---|
| เล่นเกมมาทั้งชีวิต อ่านแพทเทิร์นศัตรูเป็น | อ่านท่า (5.2) · เปิดท่าล่วงหน้า/ขัดจังหวะ (3.8) |
| รู้ว่าเข้าหาจากด้านหลังได้เปรียบ | ลอบตี ×0.4 (3.10) |
| ติดนิสัยจดวิกิเกมเอง | สมุดบันทึก (GDD 15 ขาดไม่ได้) |
| เรียกจุดพักว่า "จุดเซฟ" | จุดพัก = เซฟ (สัปดาห์ 1 มีแล้ว) |
| โอตาคุ รู้จักของโลกเก่าทุกชิ้น คนโลกใหม่บูชาเป็นเครื่องราง | อาวุธจากเศษซากสมัยใหม่ (ฉากหลัง GDD 1) |
| **คาดว่าจะมีเลเวล มี EXP → ไม่มี** | ไม่มีเลเวล ฟาร์มไม่ขึ้น (4.1) ← มุกที่สอนผู้เล่นไปพร้อมกัน |

ความรู้ของเธอ **ช่วยให้เข้าใจ ไม่ได้ทำให้เก่ง** ร่างกายยังอ่อนเหมือนเด็กที่ไม่เคยออกกำลังกาย ต้องเรียนจากอันตรายจริงเท่านั้น → ความชำนาญเริ่มที่ 8

### นิสัย
- **ช่างสังเกต พูดน้อยกับคน แต่พูดกับตัวเองเยอะ** บทพูดส่วนใหญ่เป็นเสียงในหัว เหมาะกับจอเล็กและไม่ต้องมี NPC ตอบ
- **มองโลกเป็นเกมก่อน แล้วค่อยๆ เลิก** องก์ 1 เรียกทุกอย่างด้วยศัพท์เกม ("จุดเซฟ" "มอนขยะ" "บอส")
  พอมอนตัวแรกตายถาวร เธอเลิกเรียกมันว่า "มอน" ← เส้นพัฒนาการที่วัดได้จากบทพูด ไม่ต้องมีฉากเพิ่ม
- **กลัวการผูกพัน** ชีวิตก่อนหนีคนมาตลอด ชาตินี้กลับมาได้เรื่อยๆ แต่คนอื่นไม่ได้ → ความเชื่อใจของมอนโตจากการสู้ด้วยกัน ไม่ใช่จากบทสนทนา (5.4)

### สิ่งที่เธอต้องการ vs สิ่งที่เธอจำเป็นต้องรู้
- **ต้องการ:** ใช้ชีวิตรอบนี้ให้คุ้ม ไม่เสียดายเหมือนรอบแรก
- **จำเป็นต้องรู้:** โลกนี้ไม่ใช่เกม คนที่ตายไม่กลับมา และโอกาสครั้งที่สองของเธอมีคนจ่ายราคาแทน

### สมุดบันทึก
- ระบบที่ GDD 15 บอกว่าขาดไม่ได้ ทำให้เป็น **สมุดวิกิส่วนตัวของ Riona** นิสัยจากชีวิตเกมเมอร์
- หน้าแรกเธอเขียนชื่อตัวเองกับ "กฎของโลกนี้ที่รู้แล้ว" ท่าที่ประกายได้ ท่ามอนที่อ่านได้ และเควสที่รับไว้ ถูกจดด้วยลายมือเธอ
- NG+: สมุดเล่มเดิมอยู่ที่เตาเถ้าแรก ลายมือเดียวกัน แต่เธอจำไม่ได้ว่าเขียน

## 3. ผู้ที่นับเหตุการณ์ (บอสสุดท้าย · GDD 8.5)

- ตัวตนของมันคือ Event Counter เอง **ทุกครั้งที่ EC เพิ่ม มันนับออกเสียง**
  ผู้เล่นได้ยินแค่เสียงเดียวบนจอดำสั้นๆ: "หนึ่ง" "สอง" ... (ต้นทุนผลิตต่ำ: ข้อความ 1 บรรทัดต่อ EC)
- เปิดเผยทีละน้อย:
  - องก์ 1 (EC 0-4): เสียงนับที่ไม่มีใครได้ยินนอกจาก Riona
  - องก์ 2 (EC 5-10): NPC เริ่มสังเกตว่าทุกครั้งที่เธอทำเรื่องใหญ่สำเร็จ บางอย่างในโลกพังลงนิดหนึ่ง
  - องก์ 3 (EC 11-16): เธอรู้ว่า **มันคือผู้ที่ปลุกเธอขึ้นมา** เพื่อให้ "เหตุการณ์" เกิดเร็วขึ้นจนนับครบ
- **คำถามหลักของเรื่อง: ทุกความช่วยเหลือถูกนับ**
  - ช่วยคน (จบเควสหลัก) → EC เพิ่ม → โลกเสื่อม และศัตรูแข็งขึ้น (8.2 `enemy_tier` ผูกกับ EC)
  - ไม่ช่วย → เควสหมดอายุ (`ec_max`) → หมู่บ้านถูกทำลาย
  - ไม่มีทางเลือกที่สะอาด นี่คือสิ่งที่ Free Scenario ให้ได้โดยไม่ต้องเขียนบทเพิ่ม
- ยิ่ง EC สูงตอนเข้าตอนจบ ยิ่งแรง (8.5) = ยิ่งช่วยคนมาก บอสยิ่งโต

## 4. ฉากเปิดเรื่อง (ภูมิภาค 1 · ทุ่งเถ้า · `data/map_ashfield.txt`)

เป้าความยาว **30-40 นาที** = เท่ากับ vertical slice (GDD 15 ขั้น 5)
ใช้แผนที่และข้อมูลที่มีอยู่แล้วทั้งหมด ไม่ต้องเพิ่มศัตรูหรือหีบ

| # | ที่ไหนบนแผนที่ | เกิดอะไร | กลไกที่สอน |
|---|---|---|---|
| 0 | จอดำ | เสียงหนึ่งพูดว่า "...ศูนย์" | EC เริ่มที่ 0 · ปูบอสสุดท้าย |
| 1 | `H` (มุมซ้ายบน) | Riona ตื่นบนดินเถ้า กำมีดทำครัวแน่น ภาพสุดท้ายที่จำได้คือแสงระเบิด "...นี่มันเกิดใหม่แบบในการ์ตูนเหรอ" | การเดิน |
| 2 | `R` ข้าง `H` | เตาหินเล็กๆ มีถ่านแดงที่ไม่มีฟืนแต่ไม่ดับ "จุดเซฟ... ต้องใช่แน่ๆ" เปิดสมุดเปล่า เขียนชื่อตัวเองไว้หน้าแรก | จุดพัก · เซฟ · SP เต็ม · สมุดบันทึก |
| 3 | `1` สไลม์เถ้า | ศึกแรก สไลม์แยกร่างเมื่อโดนตีเดี่ยว จบศึกแล้ว "...ไม่มี EXP? ไม่มีเลเวลเหรอ" | ลอบตีจากด้านหลัง (×0.4) · คุณค่าของ AoE · ไม่มีเลเวล |
| 4 | หญ้า `,` + `2` หนอนหิน | ศัตรูแข็งกว่าตัว ผู้เล่นเลือกหลบได้ | การหลบศึกเป็นทักษะ (3.10) |
| ◇ | ครั้งแรกที่ประกาย (เกิดเมื่อไหร่ก็ได้) | จอหยุดครึ่งวินาที "มือจำได้ก่อนหัว... นี่แหละวิธีเก่งของโลกนี้" ชื่อท่าถูกเขียนลงสมุด | ประกาย · Insight |
| ◇ | ครั้งแรกที่ล้ม (ถ้าเกิด) | ร่างสลายเป็นเถ้า ตื่นที่เตาเถ้า เงินหายครึ่ง "...อีกแล้วเหรอ" ← คำว่า "อีกแล้ว" คือเบาะแสแรกว่าเธอเคยตายมาก่อน | ความตาย · ค่าปรับ |
| 5 | `a` หีบฝั่งตะวันออก | ไม้เบสบอลอลูมิเนียม "อาวุธเริ่มต้นระดับตำนานของเกมซอมบี้" เธอรู้ทันทีว่ามันคืออะไร ← ผู้เล่นเห็นว่าความรู้โลกเก่าของเธอใช้ได้จริง | อาวุธใหม่ (ค่า 28) · ประตูอาวุธ (GDD 11.29) |
| 6 | `R` ก่อนห้องบอส (ขวาล่าง) | เตาเถ้าที่สอง เธอเริ่มสงสัยว่าใครสร้างเตาพวกนี้ | จุดพักก่อนบอส |
| 7 | `B` ราชาหนอนเถ้า | บอสแรก ชนะแล้วจอดำ เสียงเดิม "...หนึ่ง" · หญ้ารอบทุ่งเหี่ยวลงนิดหนึ่ง | บอส · EC +1 · โลกเปลี่ยนตาม EC |

### กฎของฉากเปิดเรื่อง
- **Riona อยู่คนเดียวตลอดฉากเปิด** ช่องปาร์ตี้ EC 0 = 1 ช่อง (GDD 5.5 "อยู่คนเดียว เกมโหดจริง") มอนตัวแรกมาที่ EC 2
  - ⚠ ตอนนี้ Sim และแผนที่ยังให้มอนร่วมทีม 2 ตัวตายตัว (ช่องโหว่ที่รู้แล้วใน CLAUDE.md) ทำฉากเปิดจริงเมื่อไหร่ต้องวัดบอส B1 แบบคนเดียวใหม่
- **ฉาก ◇ (ประกาย/ล้ม) ผูกกับเหตุการณ์ ไม่ผูกกับตำแหน่ง** เกิดครั้งแรกเมื่อไหร่ก็เล่นตอนนั้น ครั้งเดียว ถ้าผู้เล่นไม่เคยล้มเลย เบาะแส "อีกแล้ว" ย้ายไปพูดหลังชนะบอส
- **ไม่มีข้อความสอนเล่นแบบกล่องใหญ่** จอ 384x216 เล็ก บทพูดไม่เกิน 1 บรรทัดต่อครั้ง
- บทพูดทั้งหมดต้องอยู่ใน CSV (กฎข้อ 3 ห้าม hardcode) เช่น `data/dialogue.csv` · `id,trigger,once,text`

### ที่ต้องสร้างเพิ่มในโค้ด (ยังไม่ได้ทำ · สัปดาห์ 3-4)
- กล่องข้อความ 1 บรรทัด + ธง "เล่นแล้ว" ที่ถูกเซฟใน `PlayerState`
- จุดเรียก: เข้าแผนที่ครั้งแรก · แตะ `R` ครั้งแรก · ผล `glimmer_log` ครั้งแรก (มีใน `Battle.run()` แล้ว) · แพ้ครั้งแรก · เปิดหีบ · ชนะบอส
- จอดำ + เสียงนับ เมื่อ EC เปลี่ยน

2. อายุ 17 เท่าเดิม หรือเกิดใหม่เป็นเด็กแล้วโตขึ้นก่อนเกมเริ่ม (แบบหลังต้องมีฉากวัยเด็ก = งานเพิ่ม)
3. ผู้หญิงหรือผู้ชายในชาติก่อน (ตอนนี้ร่างเป็นผู้หญิงตามสไปรต์ · ถ้าชาติก่อนเป็นผู้ชายจะเป็นมุมเล่าเรื่องอีกแบบ)
4. ชื่อ ปิ่น / ยายขี้เถ้า เป็นชื่อชั่วคราว
