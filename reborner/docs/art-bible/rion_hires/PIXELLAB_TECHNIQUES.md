## 3. กฎเขียนคำสั่ง (ที่พิสูจน์แล้ว)

1. **8 ส่วนเสมอ** (กฎ kwan 18 ต.ค.): ทิศล็อก · ของในมือ (ขนาด/มือไหน/ทุกเฟรม) · จังหวะทีละเฟรม · หลักโมเมนตัม · ส่วนที่คงที่ · สิ่งที่ห้าม · CHARACTER + STYLE ของ `RION_MASTER.md` ตามตัวอักษร (`build_action` / `build_description`)
2. **ห้ามสั่งขัดกันเอง**: แม่แบบ State มีประโยค "stay in a true side view facing the same direction" → ท่าทุ่มที่ต้องหันหลังออกมาเป็นท่ายืนธรรมดา · ท่าที่ต้องหันหลังใช้คีย์ `facing` เขียนทิศเอง
3. **ตัวที่ไม่ใช่คน** (ผี ลูกไฟ หุ่นลอย): v3 ใช้โครงตัวคน (mannequin) บังคับ → งอกแขนขาแม้สั่งห้าม · ใช้ `pro-flash` + `template_id: "custom"` · สี่ขาใช้ `dog`/`cat`/`bear`/`horse`/`lion`
4. **ให้ลายเส้นเข้าชุด**: `pro-flash` + `style_image` = มอนชุดเดิมที่เข้าเกมแล้ว (หมาป่า M15) · `style_options.color_palette: false` (คัดแค่เส้นขอบ/เงา/รายละเอียด ไม่เอาสี) · ขนาดภาพต้องเป็นพหุคูณ 4
5. **สีตามสเปก**: ใส่ hex จาก `monster_visual_master.json` ลงคำบรรยาย (ได้ใกล้เคียง ไม่ตรงทุกจุด) · ถ้าต้องตรงเป๊ะใช้ `target_palette`
6. **ห้ามวาด VFX**: ทุกคำสั่งมี "no glowing effects / trails / speed lines" · ถึงอย่างนั้นท่าสวนยังวาดวงแสงมา → ลบด้วยโค้ด (เก็บก้อนใหญ่สุด)
7. **ไม่ให้วาดศัตรู**: ท่าจับ/ทุ่มใส่ "no opponent or second figure" แล้วโค้ดวางมอนเอง

## 4. อะไรพัง อะไรผ่าน

| ตัวจากข้อความ + ภาพแนวลายเส้น | ตัวไม่ใช่คนด้วย v3 (งอกแขนขา) |

## 5. ลำดับงานที่ได้ผล (ใช้ต่อไป)

1. **ตัวละคร** (ครั้งเดียว): ภาพ master → `character` (2 gen) หรือมอน → `pixellab_monsters.py create` (7 gen)
2. **State ท่าหลัก** ต่อสายอาวุธ/ศาสตร์ (15 gen) — ภาพนิ่ง 4 ทิศ = คีย์เฟรมที่ AI วาดถูกที่สุด
3. **ท่าสั้นจาก State** (`PL_STATE=` · `PL_START=` · 2–3 gen) เฉพาะช่วงที่ไม่หมุน
4. **ต่อด้วยโค้ด** ในหน้า animation test: คีย์เฟรม `K17(เฟรม, จุด, ภาพ, {dx, lift, lean, sq, rot, face, arc})` · ท่าหมุน = **สลับภาพมุมจริงของ State** ทีละ 1–2 เฟรม (ห้ามบีบภาพ ดูแบน · kwan 19 ต.ค.)
5. **ขยับมอนด้วยโค้ด** (`grab` ทุ่ม · `counter` วิ่งมาตี · กระเด็น · ท่าตายตามสาย/ร่างกาย)
6. ลงหน้า animation test → kwan ดู → ค่อยเข้าเกม

## 6. เรื่องจุกจิกที่ต้องรู้

- proxy ของเครื่องคลาวด์ตัดบ่อย → `call()` ลองใหม่ 5 ครั้ง (ก่อนส่งคำขอครบ ไม่เสียซ้ำ)
- ZIP ของ State/มอน ติดทั้งกลุ่มตัวละครมาด้วย (Idle/ fight_knife/ ฯลฯ) → ลบโฟลเดอร์ที่ไม่ใช่ของตัวนั้น
- ขนาดผืนไม่เท่ากัน: ตัวหลัก 124 · State 96 · ท่าจาก State 128 หรือ 96x128 → จัดเท้าลงแถว 108 ผืน 112 (แบบ `rion_pack_px`) ก่อนใช้
- ภาพหันขวาที่ PixelLab ส่งมาในหน้าเทสต้องพลิกเก็บ (หน้าเทสพลิกกลับหันซ้ายเอง · `pl_slash2` · `pl_fs10`)
- คีย์ `PIXELLAB_API_KEY` จาก env เท่านั้น · หน้า Account ของ PixelLab แสดง Secret → อย่าถ่ายภาพหน้าจอส่งต่อ

## MCP ทางการของ PixelLab + AI ตอบคำถาม (ลองจริง 20 ต.ค. 2026 · kwan ถาม "เคยคุยกับ ai ของ pixellab ไหม" → เลือก "1")
- endpoint `https://api.pixellab.ai/mcp` (MCP แบบ HTTP · header `Authorization: Bearer <PIXELLAB_API_KEY>`) · เซิร์ฟเวอร์ "PixelLab MCP Server" 0.2.0 · **103 เครื่องมือ** · รายชื่อดึงด้วย initialize + tools/list (ไม่เสียเครดิต)
- เว็บ pixellab.ai (หน้า docs / vibe-coding / ข้อตกลงการใช้งาน) **เปิดจากเครื่องคลาวด์ไม่ได้** (proxy ตอบ 403) · api.pixellab.ai ใช้ได้ · **ข้อตกลงการใช้งานยังไม่ได้อ่าน** (ลิงก์ที่ MCP แจ้ง: pixellab.ai/termsofservice)
- **`search_help` = AI ของ PixelLab ที่ถามได้** (knowledge agent ค้นเอกสารแล้วตอบสั้น) · ฟรี (ยอด 1,795 ก่อน/หลังเท่ากัน) · ถามผ่านสคริปต์ทดลอง (เรียก tools/call · ลองใหม่เมื่อเน็ตหลุด)
  ถาม 1 "มีดสลับมือ/หายกลางท่า แก้ยังไง" → ตอบ: คำสั่งข้อความคุมมือไม่ได้แน่นอน (handedness ยากสำหรับโมเดล) · แนะนำเจนตัวละครไม่ถืออาวุธ แล้ววางภาพอาวุธที่มือด้วยโค้ด/ในเกม
  ถาม 2 "สั่งห้ามแล้วยังวาดเส้นฟาด/แสง" → ตอบ: animate_character ไม่มีตัวเลือกที่รับประกัน · action_description เป็นแนวทาง ไม่ใช่ข้อบังคับ · ซ่อมด้วย `inpaint_image` (มาสก์ทับเอฟเฟกต์)
  → ตรงกับที่เราเจอเอง (bl0 รอบ 1 · bl1 รอบ 1 สลับมือ · เส้นฟาดติดทุกท่า) และวิธีที่ใช้อยู่ (clean() ลบด้วยโค้ด ฟรี · BLADE/BLADE_COPY แปะใบมีด)
- เครื่องมือที่น่าใช้กับงานเรา (ยังไม่ได้ลอง · ราคาตามคำอธิบายเครื่องมือ):
  `inpaint_image` ซ่อมเฉพาะบริเวณ ส่วนอื่นไม่เปลี่ยนสักพิกเซล (มือผิด/เศษ/เติมของในมือ) · **10 gen ต่อภาพ ≤ 256** (แพงกว่าแก้ด้วยโค้ด ใช้เมื่อโค้ดแก้ไม่ได้) ·
  `animate_with_skeleton_v3` (beta) ท่าตามโครงกระดูกที่เราจัดเองทีละเฟรม หน้าตาคงที่ · 8 เฟรม = 3 gen · ทางแก้ท่าหมุน/ทุ่มที่ข้อความสั่งไม่ได้ ·
  `pixelart_workbench` ตรวจ/ซ่อมพิกเซล (lint score repair selout shade) **ฟรีสำหรับสมาชิก** · `vfx_workbench` ทำเอฟเฟกต์เคลื่อนไหวแบบพิกเซล **ฟรี** (ส่งออก GIF/สไปรต์ชีต + JSON) ·
  `create_normal_map` 0.5 gen · `create_font` 15 gen · `wait_for_jobs` / `cancel_job` ฟรี · `agent_feedback` แจ้งปัญหาถึงทีม (อ่านทุกวัน)
