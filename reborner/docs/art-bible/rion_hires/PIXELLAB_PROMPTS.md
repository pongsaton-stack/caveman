# PixelLab · กฎเขียนคำสั่ง (kwan 18 ต.ค. 2026: "คุณต้องใส่คำสั่งให้ละเอียดที่สุด บันทึกไว้ด้วย")

ใช้กับทุกคำสั่งที่ส่ง PixelLab (`tools/sprites/pixellab_walk.py`) · ต่างจาก Flow ตรงที่ **Claude เขียนคำสั่งเอง** (kwan สั่ง) ·
ตัวละคร/สไตล์ยังยึด `RION_MASTER.md` ตามตัวอักษร

## ทำไมต้องละเอียด (บทเรียนจริง)
- ฟันมีดรอบ 1 คำสั่งสั้น 1 ประโยค → เฟรม 5–7 ตัวหมุนเข้ากล้อง · แทงตรงแทนฟันเป็นวง · ใบมีดยาว (เสีย 2 gen)
- ฟันมีดรอบ 2 เขียนทิศ + ของในมือ + ลำดับท่า + สิ่งที่ห้าม → หันซ้ายครบ 8 เฟรม มีดอยู่ทุกเฟรม ฟันเป็นวง (ผ่าน)
- สิ่งที่คำสั่งไม่ได้พูด PixelLab เดาเอง และมักเดาผิด → **ทุกเรื่องที่สำคัญต้องเขียนออกมา ห้ามปล่อยให้เดา**

## คำสั่งทุกท่าต้องมีครบ 8 ส่วน (สคริปต์ประกอบให้จาก `MOVES` · ห้ามส่งข้อความสั้นตรง ๆ)
1. **มุมมอง + ทิศ (ล็อกตลอดท่า)**: "side view, the body faces LEFT in every frame and never turns toward the camera" + จมูก/ปีกหมวก/ปลายเท้าชี้ทางไหน + เป้อยู่ข้างไหน
   ใช้บล็อก LEFT / RIGHT / BACK ของ RION_MASTER ตามตัวอักษร · ท่าในศึก = LEFT (เว้นท่าหันหลัง)
2. **ของในมือ (ถ้ามี)**: ชิ้นอะไร · ขนาดเทียบมือ ("blade about the length of the hand") · อยู่มือไหน ("front hand") · "in every frame, never disappears, never a second one"
3. **ลำดับท่าทีละจังหวะ**: เขียนเป็นข้อ 1→N ให้จำนวนจังหวะ ≈ จำนวนเฟรม (8) · แต่ละจังหวะบอก ตำแหน่งแขน/มือ · ขา (ขาไหนก้าว) · ลำตัว (เอน/ย่อ) · หัว
4. **หลักโมเมนตัม (kwan 10 ต.ค.)**: ง้างระหว่างเคลื่อน · ตีตอนน้ำหนักลง/แตะพื้น · ตามแรงต่อแล้วค่อยหยุด · ห้ามยืนนิ่งง้างค้าง
5. **ส่วนที่ต้องคงที่ทุกเฟรม**: หมวกน้ำเงินทั้งใบ + แว่นบนหมวก · เป้น้ำตาลบนหลัง · เนคไท · ตัวสูงเท่ากัน · ไม่มีนาฬิกา
6. **สิ่งที่ห้าม (NOT)**: หันเข้ากล้อง · มีดหาย/มีดสองเล่ม · ดาบยาว · เอฟเฟกต์แสงใหญ่ (VFX ใหญ่ใส่ด้วยโค้ด) · พื้น/เงา/ตัวหนังสือ
7. **ตัวละคร**: ส่ง `description` = บล็อก CHARACTER ของ RION_MASTER ตามตัวอักษร (ไม่ใช่คำย่อ)
8. **สไตล์**: บล็อก STYLE ของ RION_MASTER ตามตัวอักษร ต่อท้ายเสมอ

**บทเรียนท่าสวน/ท่ารอ (18 ต.ค.)**: คำว่า guard stance / waiting ทำให้ตัวหันเข้ากล้อง → ทุกจังหวะต้องขึ้นต้น "same side view" · PixelLab ยังวาดแสงแม้ห้าม → ลบด้วยโค้ดหลังเจน (เก็บก้อนใหญ่สุด) · ของในมือที่เล็ก (คัตเตอร์) มักกลายเป็นแสงขาวตอนเหวี่ยง

## ขั้นตอนต่อท่า
1. เพิ่มท่าใน `MOVES` ของ pixellab_walk.py (ทิศ · ของในมือ · จังหวะ · ห้าม) แล้ว `python3 tools/sprites/pixellab_walk.py prompt <ท่า>` ดูคำสั่งเต็มก่อนเสียเครดิต
2. `anim <ท่า> [ทิศ]` → `fetch` → ทำภาพเทียบ → ตรวจด้วยตาทุกเฟรม: ทิศ · ของในมือ · หน้าตา · ขนาด · ท่าตรงลำดับไหม
3. ทุกผล (ผ่าน/ไม่ผ่าน) → เพิ่มแถวใน `docs/art-bible/pixellab_test/catalog.json` → `python3 tools/web/pixellab_test_build.py` → หน้า **pixellab animation test** (มาสเตอร์) · ผ่าน → `page` → หน้า animation test · ไม่ผ่าน → บันทึกว่าพลาดอะไรในตารางข้างล่าง แล้วเพิ่มประโยคแก้ในคำสั่ง (ไม่ใช่แค่เปลี่ยน seed)
4. ทุกครั้งที่เสียเครดิต บันทึกยอดก่อน/หลังใน CLAUDE.md
