## 1. เกมนี้คืออะไร (สั้นที่สุด)

JRPG 2D พิกเซล · ศึกเทิร์นแบบคิว (แนว Romancing SaGa) · ตัวเอก **Rion** เด็กชายคนเดียวที่เริ่มจากไม่มีอะไร เรียนท่าใหม่กลางสนามรบด้วย **"ประกาย"** (หลอดไฟวาบเหนือหัวแล้วคิดท่าใหม่ออก) และเก็บมอนมาร่วมทีม

**ฉากหลัง:** โลกยุคปัจจุบันที่ล่มสลายไปแล้ว เศษของสมัยใหม่ (ที่เย็บกระดาษ ไฟแช็ก ถังแก๊ส โดรน) กระจายในซากเมือง ส่วนดาบและเวทย์คือสิ่งที่ผู้รอดชีวิตสร้างใหม่ → **อาวุธและคาถาเป็นของใช้ในบ้าน/สำนักงานที่ดัดแปลง** (มีดทำครัว ไม้เบสบอล ดินสอ หนังสติ๊ก ถุงมือ รีโมต)

**อารมณ์:** อบอุ่นแบบจิบลิในองก์แรก แล้วค่อยเสื่อมเป็นเถ้าและสนิมตามการกระทำของผู้เล่น
```
องก์ 1   เขียวชอุ่ม ฟ้าใส ทองอุ่น
องก์ 2   ลดความอิ่มตัว ฟ้าเริ่มหม่น
องก์ 3   เทาอมน้ำตาลแทนเขียว
ตอนจบ    เถ้าและสนิม เหลือเขียวเป็นจุด ๆ
```
VFX ควรสื่อว่า "พลังจากของธรรมดา" — ไม่ใช่เวทย์แฟนตาซีหรูหรา แต่ใหญ่และสะใจตอนกระทบ

## 2. กฎแนวภาพ (ห้ามหลุด)

- **พิกเซลอาร์ต 32-bit** (ยุค SNES / PS1) · พิกเซลเหลี่ยมคม · ไม่มี anti-alias · ไม่ไล่สีนุ่ม · ไม่เป็นภาพ 3D render
- **เส้นขอบเข้ม** รอบรูปทรงเอฟเฟกต์ใหญ่ ใช้สี `#2a1a14` (น้ำตาลเกือบดำ แบบเดียวกับตัวละคร)
- ลงเงาแบบการ์ตูน 2–3 ระดับ (เข้ม / กลาง / แกนขาว) ไม่ใช่ gradient
- แสงเรืองได้ แต่ทำเป็น **ชั้นพิกเซลรอบนอก** ไม่ใช่ blur ฟุ้ง (kwan ชอบ "pixel effect" มากกว่าแสงฟุ้ง)
- อนุภาคเป็นจุด/เศษพิกเซลรูปทรงต่าง ๆ — **kwan ไม่ชอบอนุภาคเป็นช่องสี่เหลี่ยมเรียงกัน**
- พื้นหลังของชีต: **เขียว chroma-key ล้วน** (`#00B140`) หรือโปร่งใส · ไม่มีตัวหนังสือ ไม่มีลายน้ำ ไม่มีเงาพื้น

### ขนาดอ้างอิง
| สิ่ง | ขนาด |
|---|---|
| จอเกม | 384 × 216 (ขยายเป็นจำนวนเต็ม) |
| Rion | สูงราว 72 จุด (ผืน 96–120 × 112) |
| มอน M / L / บอส | 48 / 96 / 96–128 |
| VFX ตีเป้าเดียว | ราว 48–96 จุด |
| VFX ทั้งแถว/ทั้งจอ | กว้างได้ถึง 384 |

### ผังจอศึก
มอนอยู่**ซ้าย** · ทีมเราอยู่**ขวา** · **Rion หันซ้ายทุกท่า** → เอฟเฟกต์โจมตีของ Rion พุ่งจาก**ขวาไปซ้าย**

สีหลักของเกม (master palette 37 สี · `docs/art-bible/master_palette.hex`) — VFX ใช้สีสดเพิ่มได้ตามธาตุ แต่ควรมีเงา/ขอบดึงกลับเข้าโทนนี้

TEAL     050708 13545C 146E77 306E76 3C5253
SHADOW   000000 150F0D 21160F 383A37 3E2214

## 4. ภาษาภาพของ 6 สายอาวุธ

| สาย | อาวุธตัวอย่าง (ระดับ 1 → 5) | ธาตุกายภาพ | ความรู้สึกที่อยากได้ |
|---|---|---|---|
| **คม** | มีดทำครัว → มีดเชฟแห่งเตาสุดท้าย | ฟัน | เสี้ยวรอยฟันโค้งคม 3 ชั้น (เข้ม/ฟ้า/แกนขาว) · ประกายเหล็ก · รอย X ค้างบนเป้า |
| **ทุบ** | ไม้เบสบอล ค้อน กระทะ | ทุบ | ดาวกระแทก · พื้นแตก · หินกระเด็น · จอสั่นแรง · คลื่นฝุ่น |
| **แทง** | ดินสอ → ปากกาผู้นับเหตุการณ์ · ไขควง | แทง | เส้นแสงพุ่งตรงทะลุออกหลังเป้า · เข็มแสงแตกรอบจุดกระทบ |
| **ยิง** | หนังสติ๊ก ธนู หน้าไม้ร่ม | แทง | แสงปากกระบอก → กระสุนเล็ก → ป๊อปที่เป้า · ห่ากระสุนจากฟ้า |
| **กล** | ที่เย็บกระดาษ รีโมต โดรน แบตเตอรี่ | ทุบ / สายฟ้า | เฟือง · สายฟ้าซิกแซก · ลำแสงจากเครื่อง · หุ่นกลไก |
| **มือเปล่า** | ถุงมือ นวม | ทุบ | ดาวหมัดรัว · ร่างแยกหลายร่าง · วงแรงอัด |

**ไม้ตาย** (ท่าระดับสูงของแต่ละสาย) = จอมืดลง · แถบชื่อท่าพาดจอ · ซูมเข้าเป้า · หยุดภาพสั้น ๆ ตอนกระทบ · ตัวหนังสือเสียงแบบมังงะ (ฉัวะ!! ตูมมม!! ฉึก!! ปัง!! ตุบ ตุบ!! ครืนนน!!)

## 6. ร่างกายมอน 9 แบบ (VFX โดน/ตายควรต่างกัน)

| ร่างกาย | ตัวอย่าง | ไอเดียตอนโดน/ตาย |
|---|---|---|
| นุ่ม | สไลม์ | กระเพื่อม · ตายไหลเยิ้มเป็นแอ่ง |
| เนื้อ | หนู หมาป่า | ผงะ · ตายผงลอยขึ้น |
| ปีก | ค้างคาว กา | ขนร่วง · ตายปลิวร่วงส่าย |
| เกราะ / หิน / กระดูก | หนอนหิน โครงกระดูกเกราะ โกเลม | ประกายไฟที่รอยกระทบ · ตายแตกเป็นก้อนกระดอนพื้น |
| กลไก | หุ่น โดรน | สายไฟช็อต ควัน · ตายระเบิดเป็นชิ้นส่วน |
| ไม้ | พืช ต้นไม้ | เศษไม้ ใบไม้ปลิว |
| วิญญาณ | ผีไฟฟ้า ตะเกียง | จางเป็นแสง · ตายสลายเป็นเปลว |

**ท่าตายตามสายที่โจมตี** (kwan ชอบ): คม = ขาดสองท่อนตามรอยฟันแล้วสลาย · ทุบ = ยุบแบนแตกเป็นก้อน · แทง = แสงรั่วจากรูแล้วหดเป็นจุด · มือเปล่า = ปลิวหมุนหลุดจอ · ไฟ = ลุกไหม้เหลือกองเถ้า · น้ำแข็ง = แข็งแล้วร้าวแตกเป็นผลึก · มืด = ถูกดูดเข้าหลุมดำ

## 7. จังหวะที่ kwan ชอบ (สำคัญ)

1. **ตามโมเมนตัม:** เคลื่อนเข้าหาเป้าแล้ว **ตีทันทีตอนถึงตัว ไม่หยุดตั้งท่า** · ง้างระหว่างเคลื่อน · จังหวะกระทบ = จังหวะแตะพื้น · หลังกระทบไถลต่อตามแรง
2. **ตามหลักฟิสิกส์:** ความร้อน → ถ่าน/ควันลอยขึ้น · ไอเย็นหนัก → เลียดพื้น หิมะร่วงช้า · แสงเร็วสุด · เศษหนักตกตามแรงโน้มถ่วงแล้วกระดอน
3. **จังหวะ VFX หนึ่งท่า:** รวมพลัง (ประกายดูดเข้าหาตัว) → ปล่อย (วาบที่มือ) → เดินทาง → **กระทบ** (วาบขาว 1–2 เฟรม + เป้าวาบ + กระเด็น) → หาง (เศษ/ควัน/ถ่านค้าง แล้วจาง)
4. ความอลังการได้เต็มที่ — kwan เคยสั่ง "อลังการกว่านี้" หลายรอบ — แต่**อย่าขาวโพลนทั้งจอ** จนมองไม่เห็นตัวละคร

## 8. สิ่งที่ห้าม / ไม่ต้องทำ

- ไม่ใส่ตัวละคร Rion หรือมอนในภาพ VFX (ถ้าจำเป็นให้เป็นเงาตำแหน่งเท่านั้น) — ตัวละครเรามีแล้ว
- ไม่วาด Rion แบบอื่น (หน้าตาต้องตรง `rion_master_v2.png` เท่านั้น)
- ไม่ใช้ตัวอักษร/ป้ายในภาพ (ตัวหนังสือเสียงใส่ด้วยโค้ด)
- ไม่ยืมเอฟเฟกต์/ภาพจากเกมจริงมาตรงตัว (เกมอื่น = แรงบันดาลใจ)
- ไม่ใช้ตัวเลขดาเมจ/ค่าเกม — VFX เป็นภาพล้วน

## 9. สิ่งที่อยากได้กลับมา (ส่งไอเดีย)

ต่อ 1 เอฟเฟกต์:
- ชื่อ + สาย/ธาตุ + คาถา/ท่าที่ใช้คู่ (เช่น "BK-2 ลมตู้แช่")
- **ชีตเฟรม** เรียงซ้าย→ขวา 6–12 เฟรม พื้นเขียวล้วน เว้นช่องไม่ให้เฟรมทับกัน · หรือ GIF/วิดีโอสั้นเพื่อดูจังหวะ
- คำอธิบายสั้นทีละจังหวะ: รวมพลัง / ปล่อย / เดินทาง / กระทบ / หาง (จังหวะไหนกี่เฟรม)
- ทิศ: ปล่อยจากขวา (Rion) ไปซ้าย (มอน)

**ลำดับที่อยากเห็นก่อน** (ยังไม่มีภาพที่ดีพอ):
1. เวทย์ดำ 6 คาถา (BK-1…BK-6) โดยเฉพาะน้ำแข็งและมืด
2. ไม้ตาย 6 สาย (คม ทุบ แทง ยิง กล มือเปล่า) ภาพละ 1 ท่าใหญ่
3. เอฟเฟกต์โดน 6 สาย (ขนาดเล็ก ใช้บ่อยทุกศึก)
4. ภาพค้างของสถานะ 6 แบบ
5. "ประกาย" ตอนคิดท่าใหม่ออก (หลอดไฟวาบเหนือหัว)
