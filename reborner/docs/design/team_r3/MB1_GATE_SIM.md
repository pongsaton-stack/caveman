# ผลจำลองประตูอาวุธ MB-1 → หีบ CR-2 → บอส B1 (ตอบข้อกังวลของ Claude)

สรุปสั้น: **ประตูไม่ผ่านตามสเตตปัจจุบัน** — ฝ่ายผู้เล่นที่เกมการันตีให้มีตอน 1.5 ชม. ชนะ MB-1 ได้ ~0% ไม่ใช่เรื่องดวง แต่เป็นโครงสร้างสเตต (รายละเอียดด้านล่าง) มีทางแก้ 2 สายพร้อมตัวเลขประกอบ

## วิธีจำลอง

- Monte Carlo 3,000 ศึกต่อกรณี สุ่มเมล็ดคงที่ ใช้สูตรที่ล็อกแล้วทั้งหมด: ดาเมจ = floor(max(1, ATK×power/100 − DEF×0.5)) × variance 0.9–1.1 · คริติคอล = min(25%, 5% + ส่วนต่าง SPD×0.001) ×1.5 · คิว AV = 10000×ActionWeight/SPD (โจมตีปกติ AW 1.0)
- ATK ผู้เล่น = 20 + ชำนาญ×1.6 + ค่าพลังอาวุธ (คำตัดสิน 26 ต.ค.) · HP/DEF/SPD ริออนจากสูตรเติบโตใน mechanics-design.md
- กลไกเฉพาะตัวที่เปิดใช้ตามสเปก: คอมโบหมาป่า ×1.6 เมื่อคิวติดกัน · โกรธเมื่อคู่ตาย (ATK +50%, AV −30%) · M06 ติดหน่วง 70% (AV ถัดไปของเป้า ×1.3) และผลุบผลับ AV −30% ครั้งเดียว · M03 เกราะแข็ง DEF +40% เมื่อ HP ต่ำ · M01 แยกร่างเมื่อโดนตี · ยาสมุนไพรฟื้น 40% HP สูงสุด (พก 3 ขวด ริออนใช้เมื่อ HP < 35%)
- ฝ่ายผู้เล่นกรณีฐาน: **ริออน (Lv.10, ชำนาญ 12, อาวุธร้านดีสุดก่อน CR-2 = Lv.2 ค่าพลัง 22) + M03 + M06** (เพื่อนร่วมทางที่เกมให้ตั้งแต่เริ่ม) กลยุทธ์ 2 แบบ: โฟกัสตัวเดียว / กระจายให้ตายพร้อมกัน (บทเรียนที่ MB-1 ออกแบบมาสอน)
- เทียบเคียง (calibration): ศึก B1 (CR-2 ค่าพลัง 28, ชำนาญ 20, ทีมเดียวกัน) โมเดลนี้ให้ชนะ 100% เทียบตัวเลข 84% ที่ Claude เคยจำลอง — โมเดลนี้ใจดีกว่าเล็กน้อย (รวมกลไกเพื่อน+ยา) ดังนั้นให้อ่านผล MB-1 เป็น "เพดานบน" ของโอกาสชนะจริง

## ผลลัพธ์

| กรณี | ชนะ |
|---|---|
| MB-1 (HP 240×2, ATK 85) — ทีมฐาน โฟกัส | 0.1% |
| MB-1 — ทีมฐาน กระจายดาเมจ | 0.1% |
| MB-1 — ทีมฐาน ชำนาญ 16 / Lv.12 | 0.0–0.1% |
| MB-1 — ทีมฐาน + M01 (ทีม 4 ตัว) | 0.5% |
| MB-1 — ทีมฐาน + คู่ M15 ที่รับเข้าทีมแล้ว | **99.7%** |
| คู่ M15 ปกติ (HP 130×2, ATK 85) — ทีมฐาน | 6.5–10.9% |

## วินิจฉัย

1. **ATK 85 ของหมาป่าวันช็อต M06** (HP 60, DEF 25 → โดน 72/ฮิต, คอมโบ 115) — ตัวสอนระบบคิวตายตั้งแต่ฮิตแรก เกมเลยไม่เหลือเครื่องมือแยกคิว (หน่วงของ M06) ให้ใช้ตามที่ศึกออกแบบไว้
2. **ดาเมจรวมของหมาป่า 2 ตัว (SPD 135 ทั้งคู่) สูงกว่าสระ HP ของทีม** — ทีมต้องทำ 480 ดาเมจ แต่โดนสวนรวม ~170 ต่อ 100 AV ขณะสระ HP ทีมรวม 595
3. **MB-1 สืบสเตต ATK/SPD จาก M15 (tier 25) มาตรง ๆ** จึงแรงกว่า B1 (ATK 75, tier 20) ทั้งที่มันคือประตูก่อนถึงอาวุธสำหรับสู้ B1 — ลำดับความแรงกลับหัว
4. ทางเดียวที่ชนะคือพาคู่ M15 มาด้วย (99.7%) แต่การรับ M15 ต้องชนะคู่ M15 ปกติก่อน ซึ่งทีมฐานชนะแค่ ~10% — โซ่การออกแบบขาดที่ข้อแรก (คู่ M15 ปกติหลบได้บนแมปเพราะเห็นตัว แต่ MB-1 เฝ้าหีบ หลบไม่ได้)

## ทางแก้ (เลือกสายเดียว)

**สาย A — ปรับสเตต MB-1 (ไม่แตะ M15/ระบบอื่น)**
| สเตต MB-1 | ชนะ (ทีมฐาน) |
|---|---|
| ATK 65, HP 240 | 4.0% |
| ATK 55, HP 200 | 56–68% |
| **ATK 55, HP 180** | **82.4%** ← ใกล้เคียงความรู้สึกประตู B1 (84%) ที่สุด |
คงกลไกคอมโบ/โกรธ/บทเรียนฆ่าพร้อมกันไว้ครบ เปลี่ยนแค่ตัวเลขประจำตัว MB-1 (แยกจาก M15 ได้เพราะ MB-1 คือ "จ่าฝูง" คนละเรคคอร์ดอยู่แล้ว)

**สาย B — คงสเตต เปลี่ยนเส้นทางเข้าถึง**
ทำให้ M15 รับเข้าทีมได้โดยไม่ต้องชนะคู่ของมันก่อน (เงื่อนไขเชิงไอเท็ม/การให้อาหารแบบเดียวกับ M01) — เส้นทางที่ออกแบบจะเป็น "รับฝูงก่อน แล้วไปท้าจ่าฝูง" (99.7% เมื่อมีคู่) และ MB-1 กลายเป็นข้อสอบของการใช้ฝูง ไม่ใช่กำแพงตัวเลข · ข้อควรระวัง: คู่ M15 ปกติยังเป็นกำแพง ~90% สำหรับการฟาร์มทั่วไป ควรพิจารณา ATK ของ M15 แยกอีกเรื่อง (probe: M15 ATK 65 → ทีมฐานชนะคู่ปกติ 73%)
