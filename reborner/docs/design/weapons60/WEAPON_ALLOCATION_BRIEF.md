### B2. คำตัดสินเพิ่ม 5 ข้อ (แบบ 1 · kwan เลือก)

1. **สถานะนับรวมในเพดาน 2 อย่าง** — ทุกชิ้นมี "ของ" ได้ไม่เกิน 2 อย่าง นับตัวปรับกฎ + สถานะรวมกัน (ข้อจำกัด / ค่าบำรุง / ชี้ทาง ไม่นับ)
   - Lv.5: ตัวปรับอ่อน 1 อย่าง เท่านั้น
   - Lv.6–8: 2 อย่าง (ตัวปรับ 2 หรือ ตัวปรับ 1 + สถานะ 1) + ข้อจำกัด 1
   - Lv.9–10: **ตัวปรับ 1 + สถานะ 1** + ค่าบำรุง · ไม่มีข้อจำกัด
2. **รับส่วนที่เหลือของชุด Kawazu ทั้งหมด**
   - สุ่มสถานะ **ครั้งเดียวต่อแอ็กชัน** (ไม่ใช่ต่อเป้า) · ท่าหลายเป้า: สุ่มครั้งเดียวแล้วติดเป้าเดียวที่โดนแรงสุด
   - อัตรา **สายดาเมจ** (พิษ · เลือดไหล): Lv.6–8 = 20% · Lv.9 = 25% · Lv.10 = 25%
   - อัตรา **สายควบคุม** (หน่วง · ตรึง · ผนึก · สับสน): Lv.6–8 = 15% · Lv.9 = 20% · Lv.10 = 20%
   - บอสติดสถานะควบคุม ×0.5
   - ตรึงเพิ่มผล: PosMult ของเป้าที่ติดตรึง −20% (ทีม Kawazu เขียนนิยามละเอียดในผลงาน)
   - เพดานการเรียนรู้: Insight ที่ได้เพิ่มจากอาวุธไม่เกิน 40% ของ Insight พื้นฐานในศึกนั้น · ดวงตานักเรียน +1 ได้ท่าละครั้งต่อศึก
   - ค่าบำรุงไม่จ่าย (B1 ข้อ 6): ครึ่งของอัตราข้างบน = 12.5% / 10%
3. **กฎในข้อ 3 ใช้เฉพาะตอนถืออาวุธที่มีตัวปรับนั้น** — ศึกที่ไม่มีตัวปรับเกี่ยวข้องทำงานตามกติกาเดิมทุกอย่าง (สมดุลที่จูนแล้วไม่ขยับ)
4. **ตัวปรับอ่อน Lv.5** เลือกจากตัวที่ลดค่าได้เท่านั้น (ห้ามตัวเปิด/ปิด เช่น ยาวถึง) · **CR-3 กระทะไม่มีความสามารถ** (Lv.3) · BD-5 ถูกกลืนเข้ากฎ Lv.5
5. **SL-10 เป็นข้อยกเว้นช่วงชี้ทาง** (Lv.10 อยู่นอกช่วงปลาย 7–9 โดยตั้งใจ — สายคมมี 4 กิ่ง)

### B3. ข้อเสนอเพิ่มจาก Claude (ทีมรับหรือแย้งได้ ระบุในผลงาน)

- ตัวปรับใหม่ที่อธิบายยาก (ส่งไม้ · จำแม่น ลืมไว · เกราะ LP สำรอง) ให้อยู่ **Lv.8 ขึ้นไป** — ผู้เล่นคุ้นระบบแล้ว
- ทุกตัวปรับต้องมี **คำอธิบายภาษาผู้เล่น ≤ 1 บรรทัด (≤ 40 ตัวอักษรไทย)** สำหรับการ์ดอาวุธ — ห้ามใช้คำว่า ActionWeight / PushMult / AV / rank
- **ลายเซ็นสาย** (Kawazu): คม = ดันคิว · แทง = ระยะ + เจาะ · ทุบ = หนักจริง · มือเปล่า = เร็วจริง · ยิง และ กล ให้ทีมกำหนด

## C. รายการตัวปรับกฎที่ใช้ได้ (20 ตัว · ห้ามสร้างเพิ่ม)

ผลทางกลไกอ้างระบบที่มีอยู่แล้วเท่านั้น · สูตรคิว `AV ถัดไป = 10000 × ActionWeight ÷ SPD × PushMult` (PushMult 0.75 เฉพาะตีโดนจุดอ่อน 1 ครั้งต่อแอ็กชัน)

**เดิม (GDD 6.1):**

| ชื่อ | ผล |
|---|---|
| คมเฉียบ | PushMult 0.65 แทน 0.75 |
| เบามือ | ActionWeight −0.15 / −0.08 (B1 ข้อ 3) |
| หนักหน่วง | ActionWeight +0.12 · ATK +25% |
| เขี้ยวคู่ | rank ที่คอมโบต้องการ −1 (ต่ำสุด 2) |
| สลักปริศนา | ThreatFactor +0.3 |
| ครูฝึก | Insight ทุกแหล่ง +50% (เพดาน B2 ข้อ 2) |
| ดวงตานักเรียน | ตั้งรับได้ความเข้าใจ +1 (ท่าละครั้งต่อศึก) |
| ยาวถึง | ตีแถวหลังไม่เสีย PosMult |
| ตลับความจำ | ช่องหน่วยความจำ +2 |
| ยันต์ชีวิต | LPmax ของมอนทุกตัว +1 |

**ใหม่ (Build Council · ทีมกำหนดตัวเลขที่ยังว่าง):**

| ชื่อ | ผล |
|---|---|
| หัวคิว | AV รอบแรกของศึก ×0.70 |
| ส่งไม้ | ดันคิวสำเร็จ → มอนเพื่อนที่คิวใกล้สุด AV −10% |
| ประกายคับขัน | ThreatFactor +0.6 เมื่อ HP < 50% |
| อ่านก่อนศึก | เจอมอนที่เคยเจอ ความเข้าใจ +1 ทันที |
| ตั้งหลักแถวหลัง | อยู่แถวหลัง PosMult 1.0 แต่ AV +10% |
| จำแม่น ลืมไว | ช่องจำ −1 แต่ท่ายึดจากมอน SP −2 |
| ประหยัด SP | ท่าที่ใช้ SP ลดต้นทุน 2 |
| ฝังสถานะ | โอกาสติด −5 จุด แต่ติดนาน 4 เทิร์น · ดาเมจสถานะ +25% |
| เกราะ LP สำรอง | ใช้ข้อจำกัด 8 หน่วยแทนการเสีย LP ของมอน |
| เครื่องทน เติมคุ้ม | จำนวนต่อการเติม ×4 ที่ค่าเติมเท่าเดิม |

**สถานะ (มีในเกม `core/Status.gd` · ติด 3 เทิร์น · โอกาสจริง = โอกาส × (1 − DEF ÷ (DEF + 120))):** พิษ (HP −6% maxHP ต่อเทิร์น) · เลือดไหล (HP −25% ของดาเมจล่าสุด) · หน่วง (AV ถัดไป ×1.3) · ตรึง (ห้ามสลับ/หนี + B2 ข้อ 2) · ผนึก (ใช้ได้แค่ท่าไม่เสีย SP) · สับสน (35% ตีพวกเดียวกัน)

**กิ่งท่า 19 กิ่ง:** คม: เขี้ยว · กวาด · ลื่นไหล · ไม้ตาย | ทุบ: สั่นสะเทือน · ถ่วง · ทลาย | แทง: จังหวะ · ระยะ · เจาะ | ยิง: กระจาย · ตั้งท่า · แม่นยำ | กล: อัตโนมัติ · รบกวน · สนับสนุน | มือเปล่า: เร็ว · ต่อเนื่อง · ประสาน

**ประเภทข้อจำกัด (หน่วยต่างกัน → ทีมตั้งจำนวนให้อายุราว 3 ศึกจริง และเขียนสมมติฐานอัตราใช้ต่อศึก):** ทนทาน (ครั้งตี) · ขว้าง (ครั้ง) · กระสุน (นัด) · แบต / พลัง (เทิร์น) · ประจุ (ครั้ง) · แรงแขน (ครั้งฟาดเต็มแรง) · ข้อมูลประกอบ: ศึกยาว 6.9–8.2 รอบ (Sim ภูมิภาค 1)
