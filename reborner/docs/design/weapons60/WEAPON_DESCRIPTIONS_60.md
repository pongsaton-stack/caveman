# คำอธิบายอาวุธ 60 ชิ้น — ชุดหลัก REBORNER (ล็อก 2026-10-26)

> อัปเดตตามคำตัดสิน kwan 2026-10-26: อาวุธทุกชิ้นใช้ได้ทุกท่าของสายตัวเอง (17 ท่า) — กลุ่ม A/B/C ในเอกสารนี้หมายถึงตระกูลท่าถือ/ต้นแบบท่าที่อาวุธชิ้นนั้นถูกออกแบบมารับเป็นหลัก ไม่ใช่ข้อจำกัดการใช้งาน

กลุ่มท่า: คม A มีดหนักครัว / B ใบยาวกวาด / C มีดเล็กชักไว · ทุบ A หัวหนักกะทัดรัด / B ด้ามยาวสองมือ / C ของแบนสั้น · แทง A ปลายสั้นแม่นยำ / B หอกยาว / C เข็มเบาเร็ว · ยิง A ง้างเล็งนัดเดียว / B ยิงพื้นที่ / C สเปรย์-แรงดัน · กล A อุปกรณ์ปล่อยตัว / B ไฟฟ้า / C กับดัก-เครื่องมือ · มือเปล่า A ชก / B จับทุ่ม-ตั้งรับ / C กรงเล็บ

## สายคม
1. **มีดทำครัว (A · Lv.1)** — มีดครัวบ้านๆ เล่มแรกของ Rion คมจริงแต่สึก ไม่มีแสง ท่าพื้นฐานสายคมทั้งหมดเริ่มจากเล่มนี้ ฟันหนักสไตล์มีดหนักครัว
2. **คัตเตอร์กล่องพัสดุ (C · Lv.2)** — คัตเตอร์เปิดลังจากงานร้าน ใบสั้นชักไว ประกายโลหะที่ใบ เปิดกลุ่มชักไวตั้งแต่ต้นเกม ใช้ท่าแทง/ฟันเร็วระยะประชิด
3. **มีดพร้าใบเลื่อย (B · Lv.3)** — พร้าใบหยักแบบเลื่อย ประกายเล็กๆ ที่ฟันเลื่อย ท่ากวาดใบยาว ฟันแล้วฉีกเป็นจังหวะเลื่อย
4. **ใบพัดพัดลมติดด้ามจับ (B · Lv.4)** — ใบพัดพัดลมตั้งพื้นถอดมาติดด้ามกลาง จับหมุนได้จริง ใช้ท่าวงล้อ/หมุนกวาด (bl4, bl12) มีลายสลักและแสงจางๆ บนใบพัด
5. **มีดเชฟแห่งเตาสุดท้าย (A · Lv.5)** — มีดเชฟเล่มโปร ออร่าไฟสีส้มเกาะคมมีดตามธีมเตา เป็นจุดเริ่มเห็นเอฟเฟกต์ชัดของสาย ใช้ท่าฟันหนักติดไฟ
6. **มีดฉาบเกี่ยว (A · Lv.6)** — มีดทรงโค้งแบบฉาบเกี่ยว เส้นพลังงานไหลตามแนวโค้งใบมีด ท่าฟันโค้งเกี่ยวดึงตามรูปทรงใบ
7. **มีดพับกลางคืน (C · Lv.7)** — มีดพับสีดำสนิท ออร่าเงามืดห่อใบมีด ท่าชักไวสายเงา ฟันเงียบและเร็ว
8. **เคียวโซ่พายุ (B · Lv.8)** — เคียวด้ามสั้นพ่วงโซ่ ขว้างแล้วดึงกลับได้ ใช้ท่าขว้าง/หมุนของกลุ่ม B (bl11 มีดบินวกกลับ) ออร่าลมเป็นวงโค้งทิศเดียวตามทางเหวี่ยง (ฉบับแก้ 2026-10-26)
9. **มีดสยองขวัญ (C · Lv.9)** — กริชต้องสาป รูนเรืองบนใบมีดและรอยมิติแตกจางๆ รอบคม ท่าชักไวขั้นสูงสายคำสาป
10. **มีดน้ำแข็ง (A · Lv.10)** — มีดเชฟเล่มใหญ่แกะจากน้ำแข็ง ออร่าน้ำแข็งหลายชั้นสว่างสุดของสาย ไม้ตายสายคม ฟันแช่แข็ง

## สายทุบ
1. **ไม้เบสบอลไม้ร้าว (B · Lv.1)** — ไม้เบสบอลไม้เก่ามีรอยร้าว ไม่มีแสง ท่าสองมือพื้นฐานของสาย ฟาดเต็มวง
2. **ไม้เบสบอลอลูมิเนียม (B · Lv.2)** — รุ่นโลหะเบา ประกายโลหะสะท้อนแสง ฟาดเร็วกว่ารุ่นไม้ เสียงกระแทกแหลม
3. **กระทะเหล็กหล่อแม่ค้า (C · Lv.3)** — กระทะเหล็กหล่อหนักจากครัวแม่ค้า ประกายเล็กที่ขอบ กลุ่มของแบนสั้น ใช้ทุบถ่วง ตรึง และล็อกอาวุธศัตรู
4. **ไม้เบสบอลหัวเฟือง (B · Lv.4)** — ไม้เบสบอลติดเฟืองโลหะที่ปลาย แสงจางที่แกนเฟือง น้ำหนักปลายไม้ทำให้ท่าฟาดสองมือหนักขึ้น
5. **ค้อนปอนด์ช่างไม้ (A · Lv.5)** — ค้อนหัวหนักของช่าง ประกายแรงกระแทกสีส้มเกาะหัวค้อน เปิดกลุ่มหัวหนัก รองรับท่าฟาดสองมือ (bt2) และสับขอบโล่ (bt8)
6. **ไม้ตะปู (B · Lv.6)** — กระบองไม้ฝังตะปูรอบตัว เส้นแสงไหลตามแนวไม้ คู่ตรงท่าคานาโบะพิฆาต (bt9) ฟาดแล้วฉีก
7. **ค้อนหนัก (A · Lv.7)** — ค้อนเหล็กหัวใหญ่ ออร่าแรงกระแทกธาตุดิน/ไฟรอบหัวค้อน ท่าหัวหนักขั้นสูง ทุบพื้นและทุบเกราะ
8. **สารานุกรมเล่มสุดท้าย (C · Lv.8)** — หนังสือเล่มยักษ์หนาหนัก ออร่าเข้มที่สันปกและขอบกระดาษ กลุ่มของแบนระบุ "หนังสือ" ตรงตัว ใช้ท่าตรึง/สกัด ฟาดด้วยน้ำหนักความรู้
9. **ไม้เบสบอลเหล็กกล้า (B · Lv.9)** — ไม้เหล็กกล้าขัดเงา วงแหวนพลังและรูนหมุนรอบกระบอกไม้ ท่าสองมือขั้นสูง
10. **ไม้เบสบอลสายฟ้า (B · Lv.10)** — ไม้เบสบอลที่สายฟ้าวิ่งทั่วกระบอก ออร่าหลายชั้นสว่างสุด ไม้ตายสายทุบ ฟาดปล่อยสายฟ้า

## สายแทง
1. **ดินสอ (C · Lv.1)** — ดินสอไม้เหลาปลายแหลมธรรมดา สึก ไม่มีแสง อาวุธแทงชิ้นแรก แทงเร็วเบาแบบเข็ม
2. **ดินสอตะปูพันเทป (C · Lv.2)** — ดินสอพันเทปยึดตะปูไว้ที่ปลายไส้ ตะปูยื่นตรงเป็นเส้นเดียวกับแกนดินสอ (ฉบับแก้ 2026-10-26) ประกายโลหะที่ตะปู แทงเจาะกว่าเดิมด้วยหัวตะปู
3. **ดินสอกดหัวเหล็ก (A · Lv.3)** — ดินสอกดปลายเหล็กแหลม ประกายเล็กที่ปลาย กลุ่มปลายแม่นยำ ใช้แทงร่องเกราะ (pt8)
4. **ปากกาหมึกซึมทหาร (C · Lv.4)** — ปากกาหมึกซึมทรงทหาร แสงจางที่หัวปากกา ท่าเฟนซิ่งแทงเร็วต่อเนื่องของกลุ่มเข็มเบา
5. **ปากกาผู้บันทึกเหตุการณ์ (C · Lv.5)** — ปากกาที่ "บันทึก" ทุกเหตุการณ์ ออร่าแสงหมึกเรือง เส้นพลังไหลตามแนวแทง ตามกติกาเฉพาะสาย ปากกา = เส้นพลัง
6. **ปากกาทำลายกระจก (A · Lv.6)** — ปากกายุทธวิธีหัวทังสเตนแข็ง พลังงานไหลรวมที่ปลายหัว กลุ่มแม่นยำสายเจาะเกราะ แทงจุดเดียวทะลุ
7. **ฉมวกสวนหลังบ้าน (B · Lv.7)** — ฉมวกสามง่ามจากงานสวน ออร่าธาตุน้ำจางๆ เปิดกลุ่มหอก แทงไกล กวาดแนว และท่าฟาลังซ์
8. **หอกดินสอ (B · Lv.8)** — หอกที่ด้ามคือดินสอยักษ์ ออร่าเข้มข้น เส้นพลังพันรอบด้าม ท่าหอกขั้นสูง แทงทะลุแถว
9. **เข็มน้ำแข็ง (C · Lv.9)** — เข็มยาวเรียวทำจากน้ำแข็ง (ฉบับแก้ให้เป็นเข็มจริงไม่ใช่ใบมีด) รูนน้ำแข็งบนก้านและรอยมิติแตกที่ปลาย แทงเร็วสายน้ำแข็ง
10. **เข็มพิษชีวภาพ (C · Lv.10)** — เข็มฉีดยาบรรจุสารชีวภาพ ออร่าเขียว/ม่วงหลายชั้น ตรงกลุ่มเข็มฉีดยาที่สุดในเกม ไม้ตายสายแทง แทงฉีดพิษ

## สายยิง
1. **หนังสติ๊กกิ่งไม้ (A · Lv.1)** — หนังสติ๊กง่ามไม้ทำเอง ไม่มีแสง ท่าง้าง-เล็ง-ปล่อยพื้นฐาน พลังงานของสายนี้อยู่ที่สายยางเสมอ
2. **หนังสติ๊กยางในรถ (A · Lv.2)** — สายยางในรถแรงดึงสูง ประกายโลหะที่ง่าม ยิงแรงและแม่นกว่ารุ่นกิ่งไม้
3. **ปืนฉีดน้ำสงกรานต์ (C · Lv.3)** — ปืนฉีดน้ำพลาสติกสีสด ประกายเล็กที่หัวฉีด เปิดกลุ่มสเปรย์/แรงดัน พ่นสกัดและเล็งนิ่ง
4. **หน้าไม้ร่มหัก (A · Lv.4)** — หน้าไม้ประกอบจากโครงร่มพัง แสงจางที่รางยิง ยิงลูกดอกเล็งนัดเดียวระยะไกล
5. **พลุกระดาษงานวัด (B · Lv.5)** — กระบอกพลุกระดาษจากงานวัด ออร่าไฟเทศกาลเกาะกระบอก เปิดกลุ่มยิงพื้นที่ ยิงกราดและห่าฝน
6. **ขวดสเปรย์พ่นสี (C · Lv.6)** — กระป๋องสเปรย์พ่นสี พลังงานไหลไปรวมที่หัวพ่น ละอองสีเป็นอนุภาค พ่นคลุมพื้นที่สกัดศัตรู
7. **หนังสติ๊กท่อเหล็ก (A · Lv.7)** — ง่ามท่อเหล็กแข็งแรง ออร่าธาตุเกาะสายยางและง่าม หนังสติ๊กสายเล็งขั้นสูง
8. **สายยางหัวฉีดดับเพลิง (B · Lv.8)** — สายยางพร้อมหัวฉีดทองเหลือง ออร่าน้ำแรงดันสูง ท่ากวาดทั้งแถว (rg3) คือการกวาดสายยางตรงตัว
9. **ถังดับเพลิงคู่ชีพ (C · Lv.9)** — ถังดับเพลิงแดงคู่ใจ วงแหวนแรงดันและรูนรอบถัง ท่าสกัด/สวนกลับของกลุ่มแรงดัน
10. **หนังสติ๊กไฟฟ้า (A · Lv.10)** — หนังสติ๊กที่สายฟ้าวิ่งทั้งง่ามและสายยาง ออร่าหลายชั้น ตำนานสายยิง ยิงนัดเดียวปล่อยสายฟ้า

## สายกล
1. **คีมช่างซ่อม (C · Lv.1)** — คีมเก่าจากกล่องเครื่องมือ สึก ไม่มีแสง เปิดกลุ่มเครื่องมือ ท่าสแกน ชี้เป้า วางกับดัก
2. **เครื่องเจียรจิ๋ว (A · Lv.2)** — เครื่องเจียรมือถือขนาดเล็ก ประกายโลหะที่ใบเจียร กลุ่มปล่อยตัวระบุตรงตัว ปล่อยบินโจมตี (dv1)
3. **สายพ่วงแบตเตอรี่ (B · Lv.3)** — สายพ่วงพร้อมขั้วหนีบทองแดง ประกายไฟฟ้าเล็กที่ขั้ว กลุ่มไฟฟ้าระบุตรงตัว ช็อตระยะประชิด
4. **สายพานเครื่องจักร (C · Lv.4)** — สายพานยางวงยาว แสงจางตามแนวสายพาน วางเป็นบ่วง/กับดัก (dv13, dv15)
5. **โดรนส่งของ (A · Lv.5)** — โดรนสี่ใบพัดพร้อมกล่องส่งของ ออร่าเรืองสีประจำตัว แกนหลักของสาย สั่งโจมตี (dv1) และฝูงกล (dv2)
6. **แบตเตอรี่พกพา (B · Lv.6)** — แบตเตอรี่ก้อนใหญ่ สัญลักษณ์สายฟ้าบนตัวเครื่อง (ฉบับแก้ 2026-10-26) เส้นแสงพลังงานวิ่งระหว่างขั้ว ใช้ปล่อยประจุ (dv3) และสนามรบกวน (dv4)
7. **แขนกลโรงงานจิ๋ว (A · Lv.7)** — แขนหุ่นยนต์ตั้งโต๊ะ ออร่าไฟฟ้า/ความร้อนที่ข้อต่อ ยิงรัว (dv7) และถือสว่านกระทุ้ง (dv8)
8. **หัวเทียนราชา (B · Lv.8)** — หัวเทียนขนาดยักษ์ ประกายพลาสมาเข้มข้นที่ขั้ว กลุ่มไฟฟ้าระบุตรงตัว พ่นประกายไฟฟ้าระยะกลาง (dv12)
9. **กล่องเครื่องมือในตำนาน (C · Lv.9)** — กล่องเครื่องมือที่เปิดแล้วมีทุกอย่าง รูนเรืองรอบกล่องและเครื่องมือข้างใน วางกับดัก/ตะขอ (dv13, dv14)
10. **โดรนแม่ทัพฝูงสวรรค์ (A · Lv.10)** — โดรนบัญชาการพร้อมฝูงโดรนบริวาร ออร่าหลายชั้น ฐานของท่าป้อมกลบุกเมือง (dv16) ที่ประกอบอุปกรณ์ทั้งสาย

## สายมือเปล่า
1. **ถุงมือผ้าทำสวน (B · Lv.1)** — ถุงมือผ้าเก่าเปื้อนดิน สึก ไม่มีแสง กลุ่มตั้งรับ ผ้าพันมือรับแรงและสวนกลับ (fs3, fs4)
2. **ถุงมือหนังเย็บน็อต (B · Lv.2)** — ถุงมือหนังเย็บหมุดโลหะ ประกายที่น็อต กลุ่ม B ระบุ "ถุงมือหนัง" ตรงตัว ชกถ่วงและบล็อก
3. **สนับมือกุญแจรถ (A · Lv.3)** — สนับมือทองเหลืองพ่วงกุญแจรถ ประกายเล็ก กลุ่มชกระบุ "สนับมือ" ตรงตัว หมัดสั้นหนัก
4. **ถุงมือสปริงประตู (A · Lv.4)** — ถุงมือติดขดสปริงประตูไว้หลังมือ แสงจางที่สปริง กลไกสปริง = ชกสะท้อน เด้งหมัดกลับแรงขึ้น
5. **ถุงมือของคนที่ไม่ยอมแพ้ (A · Lv.5)** — ถุงมือพันผ้าขาดๆ ของนักสู้ไม่ยอมถอย ออร่าสีส้มรอบหมัด ตามกติกาเฉพาะสาย ออร่าอยู่รอบหมัด หมัดต่อเนื่องสายใจสู้
6. **ถุงมือเสริมเหล็ก (B · Lv.6)** — ถุงมือบุแผ่นเหล็กหลังมือ เส้นพลังงานไหลตามแผ่นเหล็ก ตั้งการ์ดเหล็กและทุ่มถ่วงน้ำหนัก
7. **กรงเล็บเสือไฟ (C · Lv.7)** — ถุงมือลายเสือติดกรงเล็บเหล็กยาว 3 อัน (ฉบับแก้ 2026-10-26 เล็บแนวใบมีดตรง) ออร่าเปลวไฟที่เล็บ เปิดกลุ่มกรงเล็บ ท่าข่วนเร็วและไร้เงา (fs5, fs6)
8. **สนับมือหนามน้ำแข็ง (C · Lv.8)** — สนับมือหนามผลึกน้ำแข็ง ออร่าเย็นจัดเข้มข้น กลุ่ม C ระบุ "สนับมือหนาม" ตรงตัว ข่วน/ชกแช่แข็ง
9. **ถุงมือเงามืด (C · Lv.9)** — ถุงมือดำซับเงา รูนเงาบนหลังมือและขอบมิติแตกที่ปลายนิ้ว ท่าเร็วไร้เงา (fs6, fs13)
10. **ถุงมือจักรวาล (A · Lv.10)** — ถุงมือที่ผิวเป็นห้วงอวกาศดวงดาว ออร่าจักรวาลหลายชั้นรอบหมัด หมัดไม้ตาย (fs9) หมัดเดียวจบ
