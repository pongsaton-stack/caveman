- ภาพ: key pose 4 · เจนใหม่ 2

### bt2 ทำลายล้าง — เข้ากัน
- ศาสตร์: ค้อนศึกยุคกลาง (ยุโรป) · ในเกม: กระโดดสูง ฟาดลงสองมือสุดแรง
- แผนเฟรม: 0–10 ตั้งท่าค้อนพาดไหล่ ตัวต่ำเก็บแรง → 10–18 ตะโกนสั้นพร้อมกระทืบเท้าพุ่งตัว → 18–28 กระโดดขึ้น อาวุธง้างสูงสุดเหนือหัว ตัวลอยค้างสั้น → 28–34 ดิ่งลงฟาดสองมือสุดแรง →  โดนเฟรม ~32  พื้นยุบ/เศษกระเด็น → 34–44 ค้างท่าอาวุธจมพื้น ตัวก้มตามแรง พื้นยังสั่น → 44–56 ดึงค้อนขึ้น เดินกลับที่ รวม  56 เฟรม
- ภาพ: key pose 4 · เจนใหม่ 2

### bt3 กระแทกพื้น — ต้องปรับ
- ศาสตร์: ซูโม่ (ญี่ปุ่น) ชิโกะ กระทืบพื้น · ในเกม: ยกเข่าสูงแบบซูโม่ กระทืบเท้าพร้อมทุบพื้น คลื่นวิ่งไปทั้งแถว
- แผนเฟรม: 0–8 ยืนกว้างแบบซูโม่ มือเท้าต้นขา → 8–20 ยกเข่าข้างหนึ่งขึ้นสูงเปิดสะโพก ค้างโชว์ทรงชิโกะ (จังหวะนี้คือลายเซ็นของท่า อย่าตัด) → 20–26 กระทืบเท้าลงเต็มแรงพร้อมเสียงตะโกนสั้น →  คลื่นออกเฟรม ~25  วิ่งไปทั้งแถว → 26–34 ค้างท่ายืนกว้าง ตัวสั่นตามแรง พื้นร้าวเป็นทาง → 34–44 อาวุธทุบพื้นเสริมหนึ่งครั้งปิดจังหวะ (เบากว่าคลื่นแรก) → 44–52 กลับท่ายืนปกติ รวม  52 เฟรม
- จุดปรับ: ต้องปรับ  — motion เกมรวม "กระทืบเท้า" กับ "ทุบพื้นด้วยอาวุธ" ให้เกิดพร้อมกัน ทำให้ท่าอ่านไม่ออกว่าเป็นชิโกะ (ของจริงแรงมาจากเท้าเปล่าและน้ำหนักตัวล้วนๆ) จุดปรับ: แยกจังหวะให้ชัด — (1) ยกเข่าสูงเปิดสะโพกแบบชิโกะให้เห็นก่อน (2) กระทืบเท้าลง = จังหวะปล่อยคลื่น (คลื่นออกจากการกระทืบ ไม่ใช่การทุบ) (3) การทุบอาวุธลงพื้นตามมาเป็นจังหวะเสริม/ปิดท้าย หรือตัดการทุบออกให้เหลือกระทืบอย่างเดียว จะตรงศาสตร์กว่าและภาพจำชัดกว่า
- ภาพ: key pose 4 · เจนใหม่ 2

### bt4 แผ่นดินแยก — ต้องปรับ
- ศาสตร์: คทาคะดา (อินเดีย) ทุบพื้น · ในเกม: กระโดดลอย กระแทกพื้นสุดแรง รอยแยกแผ่ทั่วสนาม
- แผนเฟรม: 0–8 ตั้งท่า คทาพาดไหล่ → 8–16 ตะโกน เริ่มแกว่งคทาจากหว่างขาขึ้น → 16–32 เหวี่ยงวนรอบหลังตัวข้ามไหล่ 1 รอบเต็ม (Rumali) ความเร็วเพิ่ม ฝุ่นเริ่มฟุ้ง → 32–40 วนรอบที่สองสั้นกว่าแล้วโน้มตัวดิ่งลง → 40–46 กระแทกพื้นสุดแรง →  โดนเฟรม ~44  รอยแยกวิ่งแผ่ทั่วสนาม → 46–58 ค้างท่าคทาจมรอยแยก พื้นยังแยกต่อ/เศษดินกระเด็น → 58–68 ดึงคทาขึ้น สะบัดดิน กลับที่ รวม  68 เฟรม
- จุดปรับ: ต้องปรับ  — motion เกม ("กระโดดลอยแล้วกระแทกพื้น") ไม่มีลายเซ็นของ gada เลย แรงดูมาจากการกระโดดอย่างเดียว จุดปรับ: เพิ่มจังหวะเหวี่ยงวนคทารอบตัว/ข้ามไหล่ 1–2 รอบก่อนกระแทก เพื่อ (1) อ้างอิงวิธีใช้ gada จริง (2) ให้เหตุผลเชิงภาพว่าทำไมพื้นถึงแยกทั่วสนาม — แรงสะสมจากการวน ไม่ใช่แค่โดดทุบ และลดบทบาทการกระโดดให้เป็นแค่ตัวส่งท้าย
- ภาพ: key pose 4 · เจนใหม่ 2

### bt5 ทุบถ่วง — เข้ากัน
- ศาสตร์: โคบุโด (โอกินาวา) ทงฟา · ในเกม: ตีสั้นที่ไหล่/แขนเป้าให้ชา
- แผนเฟรม: 0–6 ตั้งท่าอาวุธแนบแขน ตัวต่ำ → 6–12 ก้าวสั้นพุ่งเข้าประชิด (ไม่ง้างอาวุธ) → 12–17 ตีสั้นเร็วเข้าไหล่/แขนเป้า →  โดนเฟรม ~16  เป้าแขนตก/ชา → 17–23 ค้างสั้นมาก ถอนตัวครึ่งก้าว → 23–32 กลับที่ รวม  32 เฟรม  (ท่าสั้นที่สุดในกลุ่มต้นสาย สมกับท่า "ถ่วง")
- ภาพ: key pose 3 · เจนใหม่ 2

### bt6 ตรึงพสุธา — เข้ากัน
- ศาสตร์: โคบุโด (โอกินาวา) ตรึงคู่ต่อสู้ · ในเกม: ทุบที่เท้าเป้าให้จมดิน ขยับไม่ได้
- แผนเฟรม: 0–8 ตั้งท่า สายตาจ้องเท้าเป้า → 8–16 ย่อตัวต่ำ ง้างอาวุธลงต่ำ (ไม่ใช่เหนือหัว — ท่านี้เล็งล่าง) → 16–21 พุ่งเข้าฟาดลงที่เท้าเป้า →  โดนเฟรม ~20  เท้าจมดิน ดินพูนรอบเท้า → 21–30 ค้างกดอาวุธไว้ที่เท้าเป้า เป้าดิ้น/ดึงเท้าไม่ออก (จังหวะขายคำว่า "ตรึง") → 30–38 ดึงอาวุธออก เป้ายังติดหล่มอีกครู่ → 38–44 กลับที่ รวม  44 เฟรม
- ภาพ: key pose 3 · เจนใหม่ 2

### bt7 ทุบเข่า — เข้ากัน
- ศาสตร์: กะลาริปะยัตตุ (อินเดีย) คทาตีจุดมัรมะที่เข่า · ในเกม: ย่อต่ำ เหวี่ยงอาวุธเลียดพื้นกวาดที่เข่า
- แผนเฟรม: 0–8 ท่ายืนต่ำผิดปกติ (ต่ำกว่าท่าอื่นในสาย) อาวุธลากใกล้พื้น → 8–16 ไถลเข้าหาเป้าในท่าต่ำ ไม่ลุกยืน → 16–22 เหวี่ยงเลียดพื้นด้วยแรงหมุนสะโพก →  โดนเฟรม ~21  เข้าข้างเข่าเป้า ขาเป้าทรุด → 22–30 ค้างท่าต่ำ อาวุธยังอยู่ระดับพื้น → 30–40 ลุกกลับท่ายืนปกติ กลับที่ รวม  40 เฟรม
- ภาพ: key pose 3 · เจนใหม่ 2

### bt8 ค้อนทลายโล่ — เข้ากัน
- ศาสตร์: ค้อนศึกยุคกลาง (ยุโรป) ด้านจะงอยเจาะโล่ · ในเกม: กลับด้านอาวุธ ใช้ขอบ/ด้านแหลมสับลงที่โล่หรือเกราะ
- แผนเฟรม: 0–8 ตั้งท่า หน้าค้อนหันเข้าหาเป้า → 8–14 ก้าวเข้า ทุบหน้าค้อนเบาใส่โล่/เกราะหนึ่งที (จังหวะหลอก) →  โดนหลอกเฟรม ~13  เป้ายกโล่รับ → 14–22 พลิกอาวุธกลับด้านอย่างชัด (จังหวะลายเซ็นของท่า ให้เวลาผู้เล่นเห็นการกลับด้าน) → 22–27 สับจะงอยลงจุดเดิมสุดแรง →  โดนจริงเฟรม ~26  โล่แตก/เกราะทะลุ → 27–35 ค้างจะงอยคาอยู่ในรอยแตก งัดออกช้าๆ → 35–44 กลับที่ รวม  44 เฟรม
- ภาพ: key pose 5 · เจนใหม่ 2

### bt9 คานาโบะพิฆาต — เข้ากัน
- ศาสตร์: คานาโบะจุตสึ (ญี่ปุ่น) กระบองเหล็กยักษ์ · ในเกม: เหวี่ยงอาวุธรอบตัวหนึ่งรอบเพิ่มแรง แล้วฟาดลงข้างหน้า พื้นแตก
- แผนเฟรม: 0–10 ตั้งท่า อาวุธลากพื้น ตัวต่ำ เสียงลากเหล็ก → 10–18 ตะโกนยาว เริ่มยกอาวุธขึ้นข้างตัว → 18–38 เหวี่ยงรอบตัวหนึ่งรอบเต็มช้าแต่หนักขึ้นเรื่อยๆ (20 เฟรม — หัวใจของท่า) ลม/ฝุ่นหมุนตาม → 38–46 อาวุธมาถึงจุดสูงสุดเหนือหัว ค้างเก็บแรง → 46–51 ฟาดลงข้างหน้าสั้นและหนักที่สุด →  โดนเฟรม ~49  พื้นแตกเป็นวง → 51–62 ค้างท่า + ตัวเซตามแรงเหวี่ยง ต้องยันเท้าก้าวตามหนึ่งก้าว (จังหวะเสียสมดุลแบบคานาโบะ) → 62–76 ผลลัพธ์: เป้ากระเด็น/พื้นยังร้าว → 76–88 ลากอาวุธกลับ กลับที่ รวม  88 เฟรม
- ภาพ: key pose 5 · เจนใหม่ 3

### bt10 เหวี่ยงคทาวงกว้าง — ต้องปรับ
- ศาสตร์: วาร์เซช-เอ-ปาห์เลวานี (อิหร่าน) เหวี่ยงมีล (กระบองคู่) · ในเกม: เหวี่ยงอาวุธเป็นวงเลขแปดกว้างหน้าตัว
- แผนเฟรม: 0–8 ตั้งท่า อาวุธพาดไหล่ขวาแบบมีล → 8–14 สะบัดอาวุธอ้อมหลังตัว (เริ่มวงแรก) → 14–24 เหวี่ยงข้ามไหล่ซ้ายลงมากวาดหน้าตัว →  โดนจังหวะแรกเฟรม ~22  กวาดทั้งแถว → 24–36 ส่งอาวุธอ้อมหลังอีกครั้ง เหวี่ยงข้ามไหล่ขวาย้อนกลับ →  โดนจังหวะสองเฟรม ~34  → 36–44 ค้างท่าอาวุธพาดไหล่ตรงข้ามจากตอนเริ่ม ลำตัวนิ่งไม่หมุน → 44–48 กลับที่ รวม  48 เฟรม
- จุดปรับ: ต้องปรับ  — สองจุด: (1) วิถีไม่ตรง: ของจริงคือวงโค้งแนวดิ่ง "จากหลังตัวข้ามไหล่มาข้างหน้า สลับข้าง" ส่วน motion เกมเป็นเลขแปดหน้าตัว ซึ่งเป็นรูปแบบของกระบองเบา/ไม้พลองมากกว่า (2) ของจริงใช้เป็นคู่ ส่วนเกมเป็นอาวุธชิ้นเดียว จุดปรับที่ยังเก็บเป้า "ตีทั้งแถว" ไว้ได้: เปลี่ยนวิถีเป็นเหวี่ยงจากหลังตัวข้ามไหล่ซ้าย 1 วง → ข้ามไหล่ขวา 1 วง สลับกัน โดยแต่ละวงกวาดโดนทั้งแถว สะโพกนิ่ง ตัวไม่หมุนตาม จะได้ทั้งความถูกต้องและภาพที่ต่างจากท่าเหวี่ยงอื่นๆ ในสาย
- ภาพ: key pose 5 · เจนใหม่ 3

### bt11 ไม้พลองกวาดสองจังหวะ — เข้ากัน
- ศาสตร์: ไม้พลองเส้าหลิน (จีน) กวาดล่าง-ฟาดบน · ในเกม: กวาดต่ำที่ขาทั้งแถว แล้วฟาดบนย้อนกลับ
- แผนเฟรม: 0–8 ตั้งท่า พลอง/อาวุธถือสองมือแนวนอนระดับเอว → 8–16 ก้าวเข้า ตัวต่ำลงครึ่งระดับ → 16–24 กวาดแนวนอนระดับขาสุดแรงหมุนสะโพก →  โดนจังหวะแรกเฟรม ~23  กวาดทั้งแถว ขาเป้าเซ → 24–30 พลองไหลต่อเนื่องไม่หยุด วนขึ้นเหนือไหล่ → 30–37 ฟาดบนย้อนกลับลงมา →  โดนจังหวะสองเฟรม ~36  → 37–46 ค้างท่าฟาด ตัวโน้มตาม → 46–52 หมุนพลองเก็บกลับท่า กลับที่ รวม  52 เฟรม
- ภาพ: key pose 4 · เจนใหม่ 3

### bt12 ค้อนธรณีพิโรธ — ต้องปรับ
- ศาสตร์: ปะห์ลวานี (อินเดีย) เหวี่ยงมุกดาร์ทุบพสุธา · ในเกม: หมุนตัวพร้อมอาวุธหลายรอบแบบเหวี่ยงค้อน ปล่อยฟาดพื้น 2 ครั้ง
- แผนเฟรม: 0–10 ตั้งท่า อาวุธพาดไหล่ซ้าย ตัวต่ำ → 10–18 ตะโกน เริ่มสะบัดอาวุธอ้อมหลังตัว → 18–34 เหวี่ยงลูกตุ้มจังหวะซ้าย: วนหลังตัวขึ้นพาดไหล่ขวา (ตัวไม่หมุน สะโพกนิ่ง) → 34–50 เหวี่ยงลูกตุ้มจังหวะขวา: วนกลับ ความเร็วและฝุ่นเพิ่มขึ้น → 50–58 โน้มตัวทุบพื้นครั้งที่หนึ่ง →  โดนพื้นครั้งที่ 1 เฟรม ~56  คลื่นแผ่ทั่วสนาม → 58–66 ดึงอาวุธขึ้นด้วยโมเมนตัมเดิม พาดไหล่ตรงข้าม → 66–74 ทุบพื้นครั้งที่สองหนักกว่า →  โดนพื้นครั้งที่ 2 เฟรม ~72  พื้นแยกเพิ่ม → 74–84 ค้างท่าอาวุธจมพื้น ตัวหอบ → 84–92 ดึงอาวุธขึ้น กลับที่ รวม  92 เฟรม
- จุดปรับ: ต้องปรับ  — motion เกมใช้การ "หมุนตัวหลายรอบแบบ hammer throw" ซึ่งไม่ใช่กลไกของมุกดาร์เลย (และภาพจะซ้ำกับ bt9 ที่เหวี่ยงรอบตัวหนึ่งรอบอยู่แล้ว) จุดปรับ: เปลี่ยนเป็น "เหวี่ยงสลับไหล่แบบลูกตุ้ม 2 จังหวะ (ซ้าย–ขวา) สะสมโมเมนตัมโดยตัวไม่หมุน" แล้วจึงทุบพื้น 2 ครั้งตามจังหวะสลับนั้น — ครั้งแรกคือปลายจังหวะซ้าย ครั้งสองคือปลายจังหวะขวา จะได้ลายเซ็นเฉพาะท่า ไม่ซ้ำ bt9 และตรงศาสตร์จริง ผลพลอยได้: ท่านี้เป็นท่า "ทั้งหมด" พลัง 75×2 การทุบ 2 ครั้งคนละจังหวะสลับยังสื่อการกระจายทั่วสนามดีกว่าหมุนตัว
- ภาพ: key pose 6 · เจนใหม่ 1

### bt13 ไซตรึงอาวุธ — เข้ากัน
- ศาสตร์: โคบุโด (โอกินาวา) ไซหนีบอาวุธคู่ต่อสู้ · ในเกม: สอดอาวุธเข้าขัดอาวุธศัตรู บิดล็อก แล้วกระแทกด้วยด้าม
- แผนเฟรม: 0–5 ตั้งท่า อาวุธชิดตัว รออาวุธศัตรูเข้ามา (ท่านี้เริ่มจากจังหวะรับ) → 5–11 อาวุธศัตรูฟาดเข้ามา สอดอาวุธเข้าไปขัดเสียงเหล็ก/ไม้ปะทะ →  ล็อกติดเฟรม ~11  → 11–17 บิดข้อมือครึ่งรอบ อาวุธศัตรูหลุดมือ/เบี่ยงออก → 17–23 กระแทกสั้นด้วยด้าม/สันเข้าตัวเป้า →  โดนเฟรม ~21  → 23–29 ค้างสั้น เป้าเสียหลักมือเปล่า → 29–36 ถอยกลับที่ รวม  36 เฟรม
- ภาพ: key pose 4 · เจนใหม่ 2

### bt14 ไม้ศอกกระแทก — เข้ากัน
- ศาสตร์: กระบี่กระบอง (ไทย) ไม้ศอกตีสั้น · ในเกม: ถืออาวุธแนบแขน ก้าวลึกแทรกแนว กระแทกตัวหลังด้วยปลายด้าม
- แผนเฟรม: 0–6 ตั้งท่า อาวุธแนบแขนทั้งสองข้าง ตัวต่ำพร้อมแทรก → 6–13 ก้าวลึกแทรกเข้าใต้แนวอาวุธศัตรู (ลึกกว่าท่าอื่นในสาย) → 13–18 สะบัดปลายอาวุธออกยืดระยะ (จังหวะลายเซ็นไม้ศอก) → 18–24 กระแทกด้วยปลายด้าม/ตัวไม้บนแขนเข้าลำตัวเป้า →  โดนเฟรม ~22  → 24–30 ค้างประชิดตัวเป้าอีกครู่ ใช้แขนอีกข้างกันไว้ → 30–36 ถอยกลับที่ รวม  36 เฟรม
- ภาพ: key pose 4 · เจนใหม่ 3

### bt15 โจสวน — ต้องปรับ
- ศาสตร์: โจจุตสึ (ญี่ปุ่น) ไม้โจรับดาบแล้วตีกลับ · ในเกม: ตั้งอาวุธทแยงหน้าตัวรอ โดนตีเมื่อไหร่ปัดแล้วตีกลับ
- แผนเฟรม: 0–14 ตั้งอาวุธทแยงหน้าตัว ค้างนิ่งรอ (จังหวะรอคือลายเซ็นของท่าเคาน์เตอร์ — ต้องมีเวลารอจริง) → 14–18 อาวุธศัตรูฟาดเข้ามา → 18–23 ปัดออกด้านข้างพร้อมหมุนข้อมือครึ่งรอบในจังหวะเดียว →  สวนโดนเฟรม ~24  เข้ากลางลำตัวเป้า (จุด suigetsu) ไม่มีการง้าง → 24–34 ค้างท่าสวน อาวุธยังคาอยู่ที่ตัวเป้า สายตานิ่ง → 34–44 ผลลัพธ์: เป้าทรุด/ถอยกระเด็น → 44–60 ดึงอาวุธกลับ ยืนตั้งท่าเดิม กลับที่ รวม  60 เฟรม
- จุดปรับ: ต้องปรับ (เรื่องอาวุธและระยะ ไม่ใช่กลไก)  — กลไก "ตั้งรอ → ปัด → ตีกลับ" ตรงกับโจจุตสึเป๊ะ แต่ปัญหาอยู่ที่อาวุธในเกม: โจของจริงยาว 128 ซม. ใช้ "สองปลาย" สวนได้ทันที ส่วนอาวุธการ์ดนี้คือของสั้น (กระทะ ไม้นวดแป้ง หนังสือ อิฐ) ที่ไม่มีปลายที่สองให้พลิก จุดปรับ: (1) นิยามการสวนใหม่เป็น "ปัดด้วยด้านหนึ่งแล้วสวนด้วยขอบ/สันอีกด้านของอาวุธชิ้นเดียวกัน" (หมุนข้อมือครึ่งรอบ ไม่ใช่พลิกปลายไม้ยาว) (2) ระยะยืนรอต้องชิดกว่าโจจริงมาก เพราะอาวุธสั้น (3) จังหวะสวนต้องเกิด "ในจังหวะเดียวกับการปัด" ไม่ใช่ปัดเสร็จแล้วค่อยง้างตี — นี่คือหัวใจของท่าที่ทำให้มันสมเป็นท่าปลายสายพลัง 150 ทั้งที่น้ำหนักอาวุธแค่ 0.6
- ภาพ: key pose 2 · เจนใหม่ 2

### bt16 ทุบสิบทิศ — เข้ากัน
- ศาสตร์: รวมศาสตร์ตะบอง/ค้อนของสาย · ในเกม: ทุบ 3 ครั้ง ซ้าย-ขวา-บน พื้นยุบทุกครั้ง ครั้งสุดท้ายกดตรึง
- แผนเฟรม: 0–10 ตั้งท่าไม้ตาย อาวุธลากพื้น ฝุ่นนิ่ง → 10–20 ตะโกนยาว เก็บแรง ตัวต่ำลงเรื่อยๆ → 20–28 ก้าวพุ่งเข้าหาเป้า → 28–36 เหวี่ยงข้างครั้งที่ 1 (ซ้าย) ด้วยแรงหมุนสะโพก →  โดนครั้งที่ 1 เฟรม ~34  พื้นยุบจุดแรก → 36–48 ไม่ต้องง้างใหม่ ใช้โมเมนตัมย้อนกลับเหวี่ยงครั้งที่ 2 (ขวา) →  โดนครั้งที่ 2 เฟรม ~46  พื้นยุบจุดที่สอง เป้าเสียหลัก → 48–62 ง้างเหนือหัวเต็มรูปแบบช้าที่สุดในท่า (จังหวะคานาโบะ) → 62–68 ฟาดลงครั้งที่ 3 →  โดนครั้งที่ 3 เฟรม ~66  หลุมยุบใหญ่สุด → 68–82 กดอาวุธค้างตรึงเป้าไว้ในหลุม (จังหวะ "ตรึง") พื้นสั่นต่อเนื่อง → 82–92 เป้าหยุดดิ้น ผลดาเมจรวมแสดง → 92–104 ดึงอาวุธขึ้น เดินกลับที่ รวม  104 เฟรม
- ภาพ: key pose 7 · เจนใหม่ 2
