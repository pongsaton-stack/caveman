REBORNER — โค้ดหลัก (Godot 4.7)
=========================================

วิธีติดตั้ง
-----------
1. ในโปรเจกต์ Godot สร้างโฟลเดอร์  core/  และ  data/
2. คัดลอกไฟล์ทั้งหมดในแพ็กนี้ลงไปตามโครงสร้าง
3. Project -> Reload Current Project
4. สร้าง Node เปล่า -> แนบ core/Sim.gd -> บันทึกเป็น scenes/sim.tscn -> กด F6

กฎที่ห้ามละเมิด
---------------
1. ลูปเทิร์นมีที่เดียวคือ Battle.run()  (GDD บทเรียน 11.15)
   ตรรกะที่เขียนซ้ำสองที่จะแตกต่างกันเสมอ
2. Sim.gd และ BattleTest.gd ต้องไม่มี class_name
   ถ้ามี class_name ซ้ำกับไฟล์อื่น ทะเบียนคลาสของ Godot จะพังทั้งโปรเจกต์
   แล้วจะขึ้น error "Could not find type X" ท่วมจอทั้งที่ไม่ได้แตะไฟล์ X
3. ห้าม hardcode ค่าใดๆ — ทุกตัวเลขมาจาก CSV หรือ Formulas.gd
4. typed array (Array[String]) ห้าม assign ด้วย literal
   ต้องใช้ .clear() แล้ว .append()
5. เยื้องด้วย tab เท่านั้น ห้ามปน space

ปัญหาที่พบบ่อย
--------------
- ตัวเลขเหมือนรอบก่อนเป๊ะทุกช่อง  -> ไฟล์ไม่ได้ถูกทับ หรือมีไฟล์ค้าง unsaved(*)
                                    ดูบรรทัด "เวอร์ชัน:" บนสุดของผล Sim ทุกครั้ง
                                    กด File -> Save All Scripts ก่อน F6 เสมอ
- "Could not find type X" ท่วมจอ  -> มี class_name ซ้ำ หรือไฟล์ core หายไป
  ตรวจว่ามีครบ 11 ไฟล์ใน core/
- CSV กลายเป็น .translation      -> คลิกไฟล์ csv -> แท็บ Import
                                    -> Import As = Keep File (No Import) -> Reimport
- แก้แล้วยังไม่หาย                 -> ปิด Godot ลบโฟลเดอร์ .godot/ แล้วเปิดใหม่
- ตัวเอกหันผิดทิศบนแมพ            -> แก้ HERO_ANIMS บนสุดของ world/Overworld.gd
- ตัวอักษรไทยเป็นกล่องสี่เหลี่ยม       -> ตั้งฟอนต์ไทยใน Project Settings -> GUI -> Theme -> Custom Font
- ตำแหน่งเซฟอยู่ไหน                -> %APPDATA%\Godot\app_userdata\<ชื่อโปรเจกต์>\reborner_save.json

วิธีรันแผนที่ (สัปดาห์ 1)
------------------------
1. คัดลอก core/ data/ world/ assets/ เข้าโปรเจกต์ (assets/sprites/hero/ มีเฟรมตัวเอก 30 ไฟล์)
2. สร้างฉากใหม่: Node2D -> แนบ world/Overworld.gd -> บันทึกเป็น scenes/overworld.tscn
3. Project Settings -> Application -> Run -> Main Scene = scenes/overworld.tscn
4. กด F5 (รันทั้งเกม ไม่ใช่ F6)

บนแผนที่
  ลูกศร        เดิน (ค้างไว้ = เดินต่อเนื่อง)
  จุดขาวบนศัตรู  ทิศที่มันหัน — เดินชนจากด้านหลัง = ลอบตี (AV ฝ่ายเรา x0.4)
  ศัตรูชนเรา     = ถูกลอบตี (AV ศัตรู x0.4)
  สีศัตรู        เทา ตบทิ้งได้ · เขียว ง่าย · เหลือง สูสี · แดง อันตราย
  ช่องสีทอง      จุดพัก: HP/SP เต็ม · บันทึกเกม · ศัตรูทั่วไปฟื้นคืน
  กล่องน้ำตาล     หีบ — มีอาวุธ tier 1 อยู่หลังฝูงหมาป่า
  F9           ลบเซฟ (ไว้ทดสอบ)

เส้นทางที่ออกแบบไว้
  prof 8 มีดทำครัว -> ล่าสไลม์/หนอน/ค้างคาว -> prof ~20
  -> หลบหมาป่า (แดง) ไปเอาหีบ -> ไม้เบสบอลอลูมิเนียม (ค่าอาวุธ 28)
  -> บอสราชาหนอนเถ้า: prof 16 ชนะ ~55% · prof 20 ~84% · prof 22 ~91%
  บอสถือมีดทำครัวไปสู้ชนะแค่ 2-10% — ตั้งใจให้เป็นประตูอาวุธ
