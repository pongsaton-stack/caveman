Rion ภาพคม ท่าขยับ

ขยับจากภาพนิ่งที่ตัดจากชีต (ไม่วาดตัวใหม่) · ท่าเปลี่ยนตามจังหวะ + ยืด/ยุบ/เอน/พุ่ง + เอฟเฟกต์วาดเส้นขอบแบบเดียวกับตัวละคร · ร่าง ยังไม่เข้าเกม

ความเร็ว
  • โจมตีใช้หลักที่ kwan ชอบ: วิ่งเข้า → ง้างระหว่างยังวิ่ง → ฟาดทันทีตอนถึงเป้า (ไม่หยุดตั้งท่า) → ไถลตามแรง → กระโดดถอยกลับ
  • หุ่นฟางเป็นเป้าชั่วคราว (ยังไม่มีมอนภาพคม) · เวลา/ระยะทั้งหมดเป็นค่าภาพในหน้านี้ ไม่ใช่ค่าเกม
  • ข้อจำกัด: เปลี่ยนท่าเป็นการสลับภาพ (มีภาพนิ่งท่าละ 1 ภาพ) · วิ่งมีภาพเดียว จึงเด้งตัวแทนการสลับขา · ถอยกลับใช้กระโดดถอย (ภาพหันขวายังไม่มี)
